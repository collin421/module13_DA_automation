정렬과 필터링
원하는 데이터만 골라내기

분석은 결국 "어떤 조건의 데이터를, 어떤 순서로 보느냐"의 반복입니다. 줄을 세우는 정렬(sort_values)과 조건에 맞는 행만 남기는 필터링(불리언 인덱싱)을 직접 만져봄. 엑셀의 정렬·필터 버튼을 코드로.

🟠 3단계 · 가공·정제 sort · 불리언 · loc · isin 예상 35분
01

정렬 — sort_values

특정 열의 값 크기에 따라 행을 다시 줄 세웁니다. ascending=True면 오름차순(작은→큰), False면 내림차순. 원본은 그대로 두고 정렬된 새 결과를 돌려줍니다. 기준을 바꿔 보세요.

인터랙티브 · sort_values

예시 8개 종목(종목명·현재가·거래량·지역). 정렬 기준을 누르면 표가 다시 줄 섭니다.

📌 참고  여러 열 기준은 리스트로(by=['지역','현재가'] → 지역으로 묶고 그 안에서 현재가순). 열마다 방향을 다르게 하려면 ascending=[True, False]. "거래량 많은 순 상위 N"처럼 랭킹의 기본 도구입니다.
3줄 요약
  1. sort_values(by=, ascending=)로 값 기준 정렬.
  2. 여러 열·방향은 리스트로 지정.
  3. 인덱스 기준 정렬은 sort_index().
02

필터의 원리 — 불리언 인덱싱

판다스 필터링의 핵심 원리입니다. ① 조건식을 쓰면 각 행에 참/거짓(True/False) 불리언 Series가 만들어지고, ② 그걸 df[...]에 넣으면 True인 행만 선택됩니다. 조건을 바꿔 두 단계를 확인해 보세요.

인터랙티브 · 조건 → True/False → 필터
① 조건식 결과 (불리언 Series) — True인 행만 ②에서 선택됨
📌 핵심  df[조건]의 "조건" 자리에는 항상 True/False로 이루어진 Series가 들어갑니다. 이 원리만 이해하면 모든 필터링이 같습니다. 비교 연산자: == 같다, != 다르다, >= <= 이상·이하.
3줄 요약
  1. 조건식 → 불리언 Series → df[불리언].
  2. True인 행만 선택됨.
  3. 모든 필터링이 이 한 가지 원리.
03

복합 조건 — AND & · OR | · NOT ~

여러 조건을 결합합니다. 파이썬의 and/or가 아니라 &/|/~를 쓰고, 각 조건을 반드시 괄호 ( )로 묶습니다. 두 조건과 결합 방식을 바꿔 매칭 행을 확인해 보세요.

인터랙티브 · & | ~
조건 A
결합
조건 B
⚠️ 가장 흔한 실수  ① and/or를 쓰면 오류(ValueError) → 반드시 &/|. ② 괄호를 빼면 우선순위 때문에 엉뚱한 결과 → 조건마다 ( ) 필수.
3줄 요약
  1. &(AND)·|(OR)·~(NOT)로 조건 결합.
  2. 각 조건은 괄호로 감싼다.
  3. and/or는 사용 불가(오류).
04

loc — 조건과 열을 동시에

df[조건]은 모든 열을 가져옵니다. 조건을 만족하는 행 중 특정 열만 보려면 loc[조건, 열목록]을 씁니다. 복잡한 조건은 변수로 빼면 읽기 쉽습니다.

인터랙티브 · loc[조건, 열]
💡 팁  조건이 길어지면 cond1 = (df['현재가']>=200000)처럼 이름을 붙여 조립하면 실수가 줄고 가독성이 좋아집니다.
3줄 요약
  1. loc[행조건, [열]]로 행·열 동시 선택.
  2. 복잡한 조건은 변수로 분리.
  3. df[조건]은 전체 열, loc는 열 한정.
05

자주 쓰는 필터 함수

비교 연산자만으로 불편한 경우를 위한 전용 메소드입니다. 목록 일치 isin, 범위 between, 문자 포함 str.contains. 탭을 바꿔 결과를 보세요.

인터랙티브 · isin · between · contains
📌 참고  isin에는 반드시 리스트를 넣습니다. between은 기본이 양끝 포함(inclusive='both'). str.contains는 문자열 열에만 쓰고, 결측이 있으면 na=False를 함께 줍니다.
3줄 요약
  1. isin(목록)·between(범위)·str.contains(포함).
  2. 여러 ==를 |로 잇는 것보다 isin이 깔끔.
  3. 필터 → 정렬 → 상위 N이 실전 패턴.
