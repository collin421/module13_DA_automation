01

분석 파이프라인 — 흩어진 도구를 하나로

지금까지 배운 것은 개별 도구였습니다. 이 파트에서는 그것을 하나의 실무 흐름으로 꿰어 봅니다. 한 문장의 과제가 곧 파이프라인입니다. 각 단계를 눌러 코드와 데이터 크기 변화를 보세요.

인터랙티브 · 분석 5단계

멤버십 회원 6,519명 → 사은품 대상 70명으로 좁혀가는 과정.

📌 한 사이클  불러오기 → 구조 파악 → 필터 → 정렬 → 저장. 이 다섯 단계가 가장 기본적인 분석 1사이클이며, 앞으로 배울 전처리·집계도 이 골격 위에 얹힙니다.
3줄 요약
  1. 과제 한 문장이 곧 분석 파이프라인.
  2. 불러오기→파악→필터→정렬→저장의 5단계.
  3. 마지막 "저장"까지 해야 분석이 완결.
02

대상 추출 — 조건으로 좁히기

조건을 변수로 만들어 조립하면 읽기 쉽습니다(Part 3). 6,519명에서 사은품 대상만 추립니다. 조건을 켜고 끄며 남는 인원을 확인해 보세요.

인터랙티브 · 조건 조합
💡 팁  필터 조건의 값은 value_counts()로 먼저 확인해야 합니다. 알람 신청 값이 '수신'인지 '신청'인지 눈으로 봐야 조건을 정확히 쓸 수 있습니다.
3줄 요약
  1. 조건은 변수로 조립(조건1 & 조건2).
  2. 6,519명 → VIP 96명 → 알람까지 70명.
  3. 조건 값은 미리 value_counts로 확인.
03

데이터 저장 — to_csv · to_excel

분석 결과(DataFrame)를 파일로 내보냅니다. 메모리 속 표를 디스크의 csv·xlsx로 "저장"합니다. index와 encoding 옵션이 단골입니다. 옵션을 바꿔 저장 결과가 어떻게 달라지는지 보세요.

인터랙티브 · 저장 옵션
index
encoding
생성된 CSV 파일 미리보기 ↓
⚠️ 꼭 기억  ① 기본값 index=True면 의미 없는 인덱스 열(0,1,2…)이 파일에 같이 저장됩니다 → 보통 index=False. ② 엑셀에서 한글이 깨지면 encoding='utf-8-sig'(또는 'cp949'). to_excel은 openpyxl 설치가 필요합니다.
3줄 요약
  1. to_csv(가볍고 호환성↑), to_excel(서식·시트).
  2. 거의 항상 index=False.
  3. 한글은 encoding='utf-8-sig'/'cp949'.

05

입력값으로 자동화 — input + f-string

input()으로 받은 값을 조건에 넣고, f-string으로 파일 이름까지 동적으로 만듭니다. 코드를 고치지 않고 입력만 바꿔 지역별·연령별 명단을 반복 생산할 수 있습니다.

인터랙티브 · 지역별 자동 저장

지역을 고르면 조건과 파일 이름이 자동으로 만들어집니다.

지역 입력:
⚠️ input은 문자열  input()은 항상 문자열을 돌려줍니다. 나이처럼 숫자로 비교하려면 int()로 변환해야 합니다 — 예: 나이 = int(input(...)) 후 df['Age'].between(최소, 최대).
3줄 요약
  1. input+f-string으로 조건·파일명을 동적으로.
  2. 입력만 바꿔 반복 생산(자동화).
  3. input은 문자열 → 숫자는 int() 변환.
