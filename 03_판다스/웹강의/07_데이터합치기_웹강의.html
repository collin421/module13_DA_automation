데이터 합치기
concat과 merge

현실에서 데이터는 한 파일에 다 들어 있지 않습니다. 같은 모양을 단순히 쌓는 concat, 공통 키로 서로 다른 정보를 엮는 merge. 흩어진 테이블을 하나로 모아 단일 표로는 보이지 않던 관계를 드러냅니다.

🔴 4단계 · 결합과 요약 concat · merge · 조인 예상 35분
01

concat — 행 방향 결합 (axis=0)

같은 열을 가진 데이터를 위아래로 쌓습니다. 1분기·2분기 데이터를 이어 붙여 상반기 전체를 만드는 식입니다. 입력은 리스트 [df1, df2]로 감쌉니다.

인터랙티브 · concat(axis=0)

ignore_index를 켜면 겹치던 인덱스가 0,1,2…로 새로 매겨집니다.

+
▼ pd.concat([df1, df2], axis=0)
📌 반복 결합  여러 파일은 for 문으로 반복해 합칩니다: for i in range(1,5): df_all = pd.concat([df_all, dfn]). 인덱스가 0,0,1,1처럼 겹치는 걸 막으려면 ignore_index=True.
3줄 요약
  1. concat([df1, df2], axis=0)으로 행 쌓기.
  2. 입력은 리스트로 감싼다.
  3. 인덱스 정리는 ignore_index=True.
02

concat — 열 방향 결합 (axis=1)

axis=1이면 좌우로 붙입니다. 한 표엔 가격, 다른 표엔 재무지표가 있을 때 옆으로 이어 항목을 늘립니다. 단, 인덱스(행 순서)가 맞아야 올바로 붙습니다.

인터랙티브 · concat(axis=1)
⚠️ 인덱스 정렬  axis=1 결합은 인덱스가 어긋나면 엉뚱한 행끼리 붙거나 결측이 생깁니다. 필요하면 미리 reset_index(drop=True)로 맞춥니다.
3줄 요약
  1. axis=1은 열을 좌우로 붙임.
  2. 행 인덱스가 맞아야 올바로 결합.
  3. 같은 구조 데이터 합산엔 concat이 편리.
03

merge — 공통 키로 엮기 (조인)

두 표를 공통된 열(키)로 짝지어 합칩니다. 엑셀 VLOOKUP, DB의 JOIN과 같습니다. 핵심은 how — 누구를 기준으로 남길지입니다. 주가(A·B·C)와 재무(B·C·D)를 종목코드로 병합하며 방식을 바꿔 보세요.

인터랙티브 · merge(how=...)
df_주가 (A·B·C)
df_재무 (B·C·D)
📌 조인 방식  inner(양쪽 모두), outer(양쪽 전체, 없으면 NaN), left/right(한쪽 전체 기준). 같은 두 표라도 how에 따라 결과 행 수가 달라지므로 분석 의도에 맞게 고릅니다. 문법: pd.merge(left, right, on='키', how=...).
3줄 요약
  1. merge(a, b, on='키', how=)로 키 기준 병합.
  2. inner=교집합, outer=합집합, left/right=한쪽 전체.
  3. how에 따라 결과 행 수가 달라짐.
04

실전 — 집계표를 정보와 결합

"회원별 구매 합계"를 구해 회원 정보(성별)와 붙이는, 실무에서 가장 흔한 패턴입니다. 집계(groupby) → 연결(merge). 단계를 눌러 보세요.

인터랙티브 · groupby → merge
📊 인사이트  결합 덕분에 "성별 구매액"처럼 원래 한 표만으로는 불가능했던 분석이 가능해집니다. 구매가 있는 회원만 보려면 inner, 미구매 회원까지 포함하려면 회원 표 기준 left/right.
3줄 요약
  1. groupby 집계표를 마스터 정보와 merge.
  2. 실무에서 가장 흔한 결합 패턴.
  3. 결합으로 새로운 각도의 분석이 열림.
05

concat vs merge — 무엇을 쓸까

둘 다 합치지만 기준이 다릅니다. 같은 모양이면 concat(위치로 쌓기), 다른 정보를 키로 엮으면 merge(값으로 짝짓기). 상황을 골라 어떤 도구가 맞는지 확인해 보세요.

인터랙티브 · 판단
3줄 요약
  1. 같은 모양 데이터 합산 → concat.
  2. 다른 정보를 키로 연결 → merge.
  3. "통합(concat)→집계(groupby)→연결(merge)" 흐름.
