01

왜 아나콘다인가

파이썬만 설치하면 NumPy·pandas·Jupyter 등을 일일이 따로 깔아야 함. 아나콘다(Anaconda)는 설치 한 번으로 파이썬 + 자주 쓰는 분석 라이브러리 수백 개 + Jupyter Notebook까지 포함된 배포판임.

핵심 도구는 conda임.

🧰 conda의 두 역할  ① 패키지 관리자 — 라이브러리 설치·업그레이드·삭제(pip과 비슷).  ② 환경 관리자 — 가상환경 생성·전환(pip엔 없는 기능). 이 두 번째가 핵심임.
📌 참고  용량이 부담되면 파이썬+conda만 든 가벼운 Miniconda도 있음. 본 강의는 아나콘다 기준임.
3줄 요약
  1. 아나콘다 = 파이썬 + 분석 라이브러리 + Jupyter + conda.
  2. conda는 패키지 관리 + 환경 관리를 모두 함.
  3. 데이터 분석 입문의 표준 출발점.
02

설치하기 (Windows)

anaconda.com에서 Windows 설치 파일을 받아 순서대로 진행함.

1anaconda.com 접속 → Download에서 Windows 64-bit 설치 파일(.exe) 내려받기.
2받은 .exe 실행 → Next → I Agree.
3설치 대상: Just Me (recommended) 선택.
4설치 경로: 기본값 유지(경로에 한글·공백 없는 곳 권장).
5옵션: "Add to PATH"는 체크 안 함(권장, 대신 Anaconda Prompt 사용) · "Register as default Python"은 체크.
6Install → 완료. 시작 메뉴에 Anaconda Prompt·Anaconda Navigator가 생김.

설치 확인

시작 메뉴에서 Anaconda Prompt(일반 cmd 아님)를 열고 입력함.

conda --version      # conda 24.x.x 처럼 나오면 성공
python --version     # Python 3.x.x
⚠️ 주의  명령은 일반 명령 프롬프트가 아니라 Anaconda Prompt에서 실행해야 conda가 인식됨. GUI를 선호하면 Anaconda Navigator로 클릭만으로 환경·Jupyter를 관리할 수 있음.
3줄 요약
  1. anaconda.com에서 Windows 설치 파일 받아 실행.
  2. "Just Me" + PATH 추가는 끄기(권장), Anaconda Prompt 사용.
  3. conda --version으로 설치 확인.
03

의존성(Dependency)이란

라이브러리는 다른 라이브러리에 기대어 동작함. 이 기댐의 사슬이 의존성임. 예를 들어 pandas는 내부적으로 NumPy를 사용하므로 pandas는 NumPy에 "의존"함. 게다가 보통 특정 버전 범위를 요구함.

버튼으로 "한 곳에 다 깔기"와 "환경 분리"를 비교해 보세요.

인터랙티브 · 의존성 충돌 vs 분리
📌 의존성 지옥  프로젝트 A는 NumPy 1.26이, 프로젝트 B는 NumPy 1.21만 필요할 때, 한 공간엔 NumPy가 하나뿐이라 둘 중 하나가 깨짐. 그래서 프로젝트마다 독립된 공간(가상환경)이 필요함.
3줄 요약
  1. 의존성 = 라이브러리가 다른 라이브러리·특정 버전에 기댐.
  2. pandas는 NumPy에 의존.
  3. 요구 버전이 달라 한 공간에 다 깔면 충돌.
04

가상환경은 왜 필요한가

가상환경은 프로젝트별로 분리된 독립 파이썬 공간임. 프로젝트마다 각자의 작업실을 주는 셈이죠. A의 도구를 바꿔도 B의 작업실엔 영향이 없음.

한 컴퓨터 안에서 환경마다 다른 파이썬 버전 / 다른 라이브러리 버전을 둘 수 있음.

🧱 장점  ① 충돌 방지(프로젝트별 버전 독립)  ② 재현성(같은 환경을 그대로 전달)  ③ 깔끔함(기본 환경 base를 더럽히지 않음). 습관: "프로젝트 하나 = 가상환경 하나".
3줄 요약
  1. 가상환경 = 프로젝트별 독립 파이썬 공간.
  2. 환경마다 파이썬·라이브러리 버전을 따로 둘 수 있어 충돌 방지.
  3. 프로젝트당 하나씩 만드는 게 권장.
05

conda 가상환경 실습

핵심 흐름은 create → activate → install → (작업) → deactivate임. 아래 버튼을 차례로 눌러 Anaconda Prompt에서 무슨 일이 일어나는지 따라가 보세요(프롬프트 맨 앞의 (환경이름)에 주목).

인터랙티브 · conda 터미널 시뮬레이터

전체 명령 정리

conda create -n myenv python=3.11   # 1) 환경 만들기
conda activate myenv                # 2) 활성화 (base)→(myenv)
conda install numpy pandas jupyter  # 3) 이 환경에만 설치
conda list                          # 4) 설치 목록
conda env list                      # 환경 목록(현재 *표시)
conda deactivate                    # 5) base로 복귀
conda env export > environment.yml  # 환경 저장(공유·재현)
conda remove -n myenv --all         # 환경 통째로 삭제
⚠️ 활성화 확인  activate를 안 하면 (base)에 깔림. 프롬프트 맨 앞의 (환경이름)을 항상 확인하세요. environment.yml로 내보내면 다른 PC에서 conda env create -f environment.yml로 똑같이 복원됨.
3줄 요약
  1. conda create -n 이름 python=버전 → conda activate 이름.
  2. 활성화 후 conda install(또는 pip)로 그 환경에만 설치.
  3. env export로 저장·공유, remove --all로 삭제.
06

Jupyter Notebook 연결

만든 가상환경에서 Jupyter를 실행하면 그 환경의 라이브러리를 그대로 사용함.

conda activate myenv
conda install jupyter ipykernel
python -m ipykernel install --user --name myenv --display-name "Python (myenv)"
jupyter notebook                    # 브라우저로 실행
📌 정리  주피터 안에서 Kernel → Change kernel → "Python (myenv)"로 환경을 선택함. 또는 Anaconda Navigator에서 환경을 고른 뒤 Jupyter를 Launch 하면 됨.
3줄 요약
  1. 환경 활성화 후 jupyter notebook 실행.
  2. ipykernel로 환경을 주피터 커널로 등록.
  3. Navigator로 클릭만으로도 실행 가능.
