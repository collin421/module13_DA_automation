NumPy 기초
판다스의 엔진, 배열과 연산

판다스의 Series·DataFrame은 NumPy 배열 위에 세워져 있음. 판다스가 대량의 숫자를 빠르게 다루는 비결인 NumPy의 핵심 — 벡터 연산, 배열 구조, 브로드캐스팅, 축(axis) 집계 — 을 직접 만져보며 익힘. 이 개념들이 그대로 판다스로 이어짐.

01

리스트 vs 배열 — 벡터 연산의 힘

NumPy를 배우는 가장 강력한 이유입니다. 두 묶음의 숫자를 더해 봅시다. 파이썬 리스트에서 +는 더하기가 아니라 이어붙이기입니다. 반면 NumPy 배열은 같은 위치 요소끼리 한 번에 계산합니다(벡터 연산).

인터랙티브 · 리스트 vs 배열

연산을 바꿔 보며, 같은 입력에 대해 리스트와 배열이 어떻게 다르게 동작하는지 비교해 보세요.

list2456

📌 핵심  NumPy는 반복문 없이 배열 전체를 한 번에 계산합니다(벡터화). 수만 개의 숫자도 순식간에 처리하는 비결이며, 판다스의 df['가격'] * 0.9 같은 연산이 모두 이 원리입니다.

왜 리스트보다 빠를까 — 그리고 판다스의 엔진

같은 계산이라도 NumPy 배열이 파이썬 리스트보다 훨씬 빠릅니다. 리스트는 요소를 하나씩 파이썬 반복문으로 처리하지만, NumPy는 연속된 메모리에 같은 자료형을 모아 두고 C로 구현된 코드가 한 번에 계산하기 때문입니다(벡터화). 데이터가 클수록 차이는 수십~수백 배로 벌어집니다.

🧱 판다스의 기초  판다스는 NumPy 위에 세워진 라이브러리입니다. Series·DataFrame의 값은 내부적으로 NumPy 배열(ndarray)로 저장되고, df['가격'] * 0.9·.sum()·.mean() 같은 빠른 연산이 모두 NumPy 엔진에서 나옵니다. 그래서 NumPy를 알면 판다스가 쉬워집니다.
3줄 요약
  1. 리스트의 +는 연결, 배열의 +는 요소별 덧셈.
  2. 배열은 반복문 없이 C 엔진으로 한 번에 계산 → 리스트보다 수십~수백 배 빠름.
  3. 이 벡터 연산이 판다스(Series·DataFrame)의 기초이자 고속 계산의 토대.

배열 만들기와 데이터 유형

np.array()로 리스트를 배열로 바꿉니다. 배열의 모든 요소는 같은 자료형(dtype)을 가집니다. 그 밖에 0·1·일정 간격으로 채우는 생성 함수가 있습니다. 각 함수를 눌러 결과와 dtype을 확인해 보세요.

인터랙티브 · 배열 생성 함수
📌 참고  np.arange(start, stop, step)는 파이썬 range의 배열 버전으로, stop은 포함하지 않습니다. dtype은 자동 추론되며 dtype=float처럼 직접 지정할 수도 있습니다.
3줄 요약

  2. 배열의 모든 요소는 같은 dtype(int·float·bool).
  3. arange의 stop은 미포함(range와 동일).
03

ndarray의 구조 — ndim · shape · size

ndarray(다차원 배열)의 모양은 세 가지 속성으로 파악합니다(속성이라 괄호 없음). ndim(차원), shape(행·열), size(전체 개수). 차원을 바꿔 보며 값이 어떻게 달라지는지 보세요.

인터랙티브 · 배열의 차원
📌 판다스로 직결  DataFrame의 .shape, .ndim이 바로 이 NumPy 속성에서 왔습니다. "2행 3열" 같은 모양 읽기는 분석의 기본기입니다.
3줄 요약
  1. ndim=차원, shape=(행,열), size=전체 개수.
  2. 1차원=한 줄, 2차원=행렬(표), 3차원=표 여러 장.
  3. 속성이라 괄호 없이 arr.shape로 접근.
04

인덱싱과 슬라이싱

원하는 요소·구간을 꺼냅니다. 인덱스는 0부터 시작하고, 2차원은 [행, 열]로 접근합니다. 슬라이싱은 start:stop:step이며 stop은 제외됩니다. 아래 3×3 배열에서 식을 골라 선택 영역과 결과를 확인해 보세요.

인터랙티브 · 2차원 인덱싱·슬라이싱
arr2 (3×3)
📌 판다스로 직결  2차원 슬라이싱 [행범위, 열범위]는 판다스의 iloc[행, 열]과 똑같은 원리입니다. NumPy에서 먼저 익히면 판다스가 쉬워집니다.
3줄 요약
  1. 인덱스는 0부터, 2차원은 [행, 열].
  2. 슬라이싱 start:stop:step, stop은 미포함.
  3. 음수 인덱스는 뒤에서부터(-1=마지막).
05

배열 연산과 브로드캐스팅

배열끼리는 같은 위치 요소끼리 자동 계산됩니다. 또한 배열과 숫자 하나(스칼라)를 연산하면 그 숫자가 모든 요소에 자동 적용됩니다 — 이것이 브로드캐스팅입니다. 슬라이더로 스칼라 값을, 버튼으로 연산을 바꿔 보세요.

인터랙티브 · 브로드캐스팅
arr102030 +5
스칼라 값: 5 (모든 요소에 적용됨)
📌 데이터 분석  "모든 가격에 10% 할인" 같은 작업이 arr * 0.9 한 줄로 끝납니다. 판다스의 df['가격'] * 0.9가 바로 이 브로드캐스팅입니다.

다양한 브로드캐스팅 — 한 줄을 넘어 2차원으로

브로드캐스팅은 스칼라에만 그치지 않습니다. 모양(shape)이 맞으면 작은 배열이 큰 배열에 맞춰 자동으로 늘어나(stretch) 계산됩니다. 스칼라 → 행 벡터 → 열 벡터 → 격자까지, 버튼으로 형태를 바꿔 어떻게 확장되는지 보세요.

인터랙티브 · 다양한 브로드캐스팅
📏 규칙  두 배열의 모양을 뒤쪽 축부터 맞춰 보아, 크기가 같거나 한쪽이 1이면 그 축으로 늘려서(broadcast) 계산합니다. (3,3)+(3,)는 행마다, (3,1)은 열마다 적용되고, (3,1)+(1,3)은 (3,3) 격자(구구단표 같은)가 됩니다.
3줄 요약
  1. 배열끼리는 같은 위치 요소끼리, 스칼라는 모든 요소에 적용.
  2. 모양이 맞으면(한쪽 축이 1) 작은 배열이 자동 확장 — 행 벡터=행마다, 열 벡터=열마다.
  3. (3,1)+(1,3)→(3,3) 격자까지, 반복문 없이 한 줄로.
06

집계 함수와 축(axis) — 가장 중요

배열의 합·평균·최소·최대를 계산합니다. 핵심은 축(axis)입니다. axis=0은 세로(↓)로 내려가며 계산해 열별 결과를, axis=1은 가로(→)로 가며 계산해 행별 결과를 줍니다. 토글하며 계산 방향과 결과를 확인해 보세요.

인터랙티브 · axis 집계
⚠️ axis 헷갈림 주의  axis=0은 "행 방향으로 내려가며" 계산해 열별 결과를, axis=1은 "열 방향으로 가며" 계산해 행별 결과를 줍니다. "0=세로축, 1=가로축"으로 기억하세요.
3줄 요약
  1. sum·mean·min·max로 집계.
  2. axis=0=열별, axis=1=행별.
  3. 이 축 개념이 판다스 groupby·pivot_table의 뿌리.
