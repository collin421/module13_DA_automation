# 선행 ② 아나콘다 · 의존성 · 가상환경 — 내용 초안 (Windows 기준)

> 한 줄 요약: 데이터 분석에 필요한 파이썬과 라이브러리를 한 번에 깔아주는 **아나콘다**를 설치하고, 라이브러리 **버전 충돌**을 막는 **가상환경**을 만드는 법을 익힌다.

## 0. 들어가며 (히어로)
- 부제: "환경을 갖추고 깔끔하게 관리하기"
- 리드: 라이브러리를 마구 깔다 보면 **"A는 최신 버전이 필요한데 B는 옛 버전이 필요"** 한 충돌이 생깁니다. 아나콘다는 분석에 필요한 도구를 한 번에 깔아주고, **가상환경**으로 프로젝트마다 깨끗하게 분리해 줍니다.
- 칩: ⚙️ 선행 학습 · Anaconda · conda · 예상 30분

## 1. 왜 아나콘다인가
**핵심:** 아나콘다 = **파이썬 + 데이터 분석 라이브러리 + 관리 도구**를 한 번에 묶은 배포판.

- 파이썬만 설치하면 NumPy·pandas·Jupyter 등을 일일이 따로 깔아야 함.
- **아나콘다(Anaconda)**: 설치 한 번으로 파이썬 + 자주 쓰는 분석 라이브러리 수백 개 + Jupyter Notebook까지 포함.
- 핵심 도구 **conda**: 
  - **패키지 관리자** — 라이브러리 설치/업그레이드/삭제 (pip과 비슷).
  - **환경 관리자** — 가상환경 생성/전환 (pip엔 없는 기능).
- 용량이 부담되면 가벼운 **Miniconda**(파이썬+conda만)도 있음 — 본 강의는 아나콘다 기준.

> 📌 정리: "파이썬 + 분석 라이브러리 + Jupyter + 환경관리(conda)"를 한 방에. 데이터 분석 입문의 표준 출발점.

## 2. 설치하기 (Windows)
**단계 (시각화 대상 — 스텝 카드):**
1. 브라우저에서 **anaconda.com** → Download(또는 Free Download)에서 **Windows 64-bit** 설치 파일(.exe) 내려받기.
2. 받은 `.exe` 실행 → Next → I Agree.
3. 설치 대상: **"Just Me (recommended)"** 선택(권장).
4. 설치 경로: 기본값 유지(경로에 **한글·공백 없는** 곳 권장).
5. 옵션 화면:
   - ☐ "Add Anaconda3 to my PATH" — **체크 안 함(권장)**. 대신 **Anaconda Prompt**를 사용.
   - ☑ "Register Anaconda3 as my default Python" — 체크(기본).
6. Install → 완료.

**설치 확인:**
- 시작 메뉴에서 **Anaconda Prompt** 실행(일반 cmd 아님).
```bash
conda --version      # conda 24.x.x 처럼 버전이 나오면 성공
python --version     # Python 3.x.x
```
- **Anaconda Navigator**(GUI)로도 환경·앱(Jupyter 등)을 클릭으로 관리 가능.

> ⚠️ 주의: 명령은 일반 명령 프롬프트가 아니라 **Anaconda Prompt**에서 실행해야 conda가 인식됩니다.

**3줄 요약**
1. anaconda.com에서 Windows 설치 파일 받아 실행.
2. "Just Me" + PATH 추가는 끄기(권장), Anaconda Prompt 사용.
3. `conda --version`으로 설치 확인.

## 3. 의존성(Dependency)이란
**핵심:** 라이브러리는 **다른 라이브러리에 기대어** 동작한다. 이 기댐의 사슬이 의존성.

- 예: **pandas**는 내부적으로 **NumPy**를 사용 → pandas는 NumPy에 "의존"한다.
- 라이브러리는 보통 **특정 버전 범위**를 요구함. 예: "패키지 X는 NumPy 1.24 이상 필요".
- **버전 충돌(의존성 지옥, dependency hell):** (충돌 시각화 대상)
  - 프로젝트 A: `라이브러리X`가 **NumPy 1.26** 필요
  - 프로젝트 B: `라이브러리Y`가 **NumPy 1.21** 만 지원
  - 한 곳에 다 깔면 NumPy 버전이 하나뿐이라 **둘 중 하나가 깨진다.**
- 그래서 프로젝트마다 **독립된 공간**이 필요 → 가상환경.

> 📌 핵심: 라이브러리를 깔면 그 라이브러리가 의존하는 다른 라이브러리도 (버전에 맞춰) 함께 깔린다. 버전이 어긋나면 충돌.

**3줄 요약**
1. 의존성 = 라이브러리가 다른 라이브러리·특정 버전에 기댐.
2. pandas는 NumPy에 의존.
3. 프로젝트마다 요구 버전이 달라 한 공간에 다 깔면 충돌.

## 4. 가상환경은 왜 필요한가
**핵심:** 가상환경 = **프로젝트별로 분리된 독립 파이썬 공간.** (격리 다이어그램 대상)

- 비유: 프로젝트마다 **각자의 작업실**을 준다. A의 도구를 바꿔도 B의 작업실엔 영향 없음.
- 한 컴퓨터 안에서 환경마다 **다른 파이썬 버전 / 다른 라이브러리 버전**을 둘 수 있다.
- 장점:
  - 충돌 방지(프로젝트별 버전 독립).
  - 재현성 — 같은 환경을 남에게 그대로 전달 가능.
  - 깔끔함 — 기본 환경(base)을 더럽히지 않음.
- 그림: [기본 환경에 전부] ❌ 충돌 vs [환경A | 환경B | 환경C 분리] ✅ 안전.

> 📌 정리: "프로젝트 하나 = 가상환경 하나"가 안전한 습관.

**3줄 요약**
1. 가상환경 = 프로젝트별 독립 파이썬 공간.
2. 환경마다 파이썬·라이브러리 버전을 따로 둘 수 있어 충돌 방지.
3. 프로젝트당 하나씩 만드는 게 권장.

## 5. conda 가상환경 실습 (명령어)
**핵심 명령 (터미널 시뮬레이터 위젯 대상 — 버튼 누르면 가상 출력):**

```bash
# 1) 환경 만들기 (이름 myenv, 파이썬 3.11 지정)
conda create -n myenv python=3.11

# 2) 환경 활성화 (프롬프트 앞이 (base) → (myenv)로 바뀜)
conda activate myenv

# 3) 라이브러리 설치 (이 환경 안에만 설치됨)
conda install numpy pandas jupyter
#  또는  pip install 패키지   (conda에 없을 때)

# 4) 설치 목록 확인
conda list

# 5) 환경 목록 보기 (현재 환경엔 * 표시)
conda env list

# 6) 비활성화 (기본 base로 돌아감)
conda deactivate

# 7) 환경 내보내기 / 삭제
conda env export > environment.yml      # 환경을 파일로 저장(공유·재현)
conda remove -n myenv --all             # 환경 통째로 삭제
```

- 핵심 흐름: **create → activate → install → (작업) → deactivate**.
- `(base)`는 아나콘다 기본 환경 — 실습/프로젝트는 새 환경을 만들어 쓰는 걸 권장.
- `environment.yml`로 내보내면 다른 컴퓨터에서 `conda env create -f environment.yml`로 **똑같이 복원**.

> ⚠️ 주의: 활성화(`activate`)를 안 하면 base에 깔린다. 프롬프트 맨 앞의 `(환경이름)`을 항상 확인.

**3줄 요약**
1. `conda create -n 이름 python=버전` → `conda activate 이름`.
2. 활성화한 뒤 `conda install`(또는 pip)로 그 환경에만 설치.
3. `env export`로 저장·공유, `remove --all`로 삭제.

## 6. Jupyter Notebook 연결
**핵심:** 만든 가상환경에서 Jupyter를 실행해 그 환경의 라이브러리를 그대로 사용.

```bash
conda activate myenv
conda install jupyter ipykernel        # (없으면 설치)
python -m ipykernel install --user --name myenv --display-name "Python (myenv)"
jupyter notebook                        # 브라우저로 주피터 실행
```
- 주피터 안에서 **Kernel → Change kernel → "Python (myenv)"** 로 환경 선택.
- 또는 **Anaconda Navigator**에서 환경 선택 후 Jupyter를 Launch.

> 📌 정리: "환경 활성화 → (필요 시 커널 등록) → jupyter notebook" 이면 그 환경에서 분석 시작.

**3줄 요약**
1. 환경 활성화 후 `jupyter notebook` 실행.
2. `ipykernel`로 환경을 주피터 커널로 등록 가능.
3. Navigator로 클릭만으로도 실행 가능.
