## 1. 데이터 정렬하기

### 1-1. `sort_values()` — 값을 기준으로 정렬

**개념**: 특정 열의 **값** 크기에 따라 행을 다시 줄 세웁니다.

**원리**: 원본은 그대로 두고 **정렬된 새 DataFrame을 반환**합니다(기본). 인덱스는 따라 움직이므로, 정렬 후에도 어떤 행이 어디서 왔는지 인덱스로 알 수 있습니다.

**문법 / 인수**
```python
df.sort_values(by, ascending=True, inplace=False)
```

| 인수 | 의미 | 기본값 |
|---|---|---|
| `by` | 정렬 기준 열(이름 또는 리스트) | (필수) |
| `ascending` | 오름차순(작은→큰) | `True` (`False`면 내림차순) |
| `inplace` | 원본에 바로 적용 | `False` |

**사용법**
```python
df.sort_values(by='현재가')          # 현재가 오름차순(낮은 가격부터)
```
```
        종목명    현재가     거래량  지역
15     한국전력  18000  500000  서울
16  LG디스플레이  19000  300000  서울
8      신한지주  42000  650000  서울
...
```
```python
df.sort_values(by='현재가', ascending=False)   # 내림차순(비싼 종목부터)
```

**여러 열 기준 정렬** — `by`에 리스트. 앞 열로 먼저 정렬하고, 같은 값이면 다음 열로.
```python
df.sort_values(by=['지역', '현재가'])           # 지역별로 묶고, 그 안에서 현재가순
```

**열마다 방향 다르게** — `ascending`에도 리스트.
```python
# 현재가는 오름차순, 거래량은 내림차순
df.sort_values(by=['현재가', '거래량'], ascending=[True, False])
```

> 📊 "거래량 많은 순 정렬 후 상위 10개"처럼, 정렬은 **랭킹·Top-N 분석**의 기본 도구입니다.

### 1-2. `sort_index()` — 인덱스를 기준으로 정렬

**개념**: 값이 아니라 **인덱스(행 이름표 또는 열 이름)** 순으로 정렬합니다. 필터링·정렬로 뒤섞인 순서를 원래대로 되돌릴 때 유용합니다.

**문법 / 인수**
```python
df.sort_index(axis=0, ascending=True, inplace=False)
```

| 인수 | 의미 | 기본값 |
|---|---|---|
| `axis` | `0`=행 인덱스, `1`=열 이름 기준 | `0` |
| `ascending` | 오름차순 | `True` |

```python
df.sort_index()           # 행 인덱스 0,1,2… 순으로
df.sort_index(axis=1)     # 열 이름을 가나다/알파벳 순으로
```

> 💡 `sort_values`는 **값**, `sort_index`는 **이름표** 기준. 헷갈리지 마세요.

## 2. 필터링 — 조건에 맞는 행만 뽑기

### 2-1. 원리: 불리언 인덱싱(Boolean Indexing)

판다스 필터링의 핵심 원리입니다. **2단계**로 일어납니다.

**1단계** — 조건식을 쓰면 각 행에 대해 참/거짓(True/False) **불리언 Series**가 만들어집니다.
```python
df['현재가'] >= 200000
```
```
0     False
1     False
2      True     # NAVER 380000 → 조건 만족
3     False
...
Name: 현재가, dtype: bool
```

**2단계** — 이 불리언 Series를 `df[...]`에 넣으면 **True인 행만** 선택됩니다.
```python
df[df['현재가'] >= 200000]      # 현재가 20만 원 이상인 종목만 (9개)
```
```
     종목명     현재가
2  NAVER  380000
4   LG화학  800000
5    현대차  200000
...
```

> 💡 즉 `df[조건]`의 "조건" 자리에는 항상 **True/False로 이루어진 Series**가 들어갑니다. 이것만 이해하면 모든 필터링이 같은 원리입니다.

**비교 연산자** (조건을 만드는 도구)

| 연산자 | 의미 | 예 |
|---|---|---|
| `==` | 같다 | `df['지역'] == '서울'` |
| `!=` | 다르다 | `df['지역'] != '서울'` |
| `>` `>=` | 초과 / 이상 | `df['현재가'] >= 200000` |
| `<` `<=` | 미만 / 이하 | `df['거래량'] < 500000` |

```python
df[df['지역'] == '서울']     # 서울 종목만
df[df['지역'] != '서울']     # 서울이 아닌 종목만
```

### 2-2. 복합 조건 — AND `&`, OR `|`, NOT `~`

여러 조건을 결합합니다. **파이썬의 `and`/`or`가 아니라 `&`/`|`/`~`를 쓰고, 각 조건을 반드시 괄호 `()`로 묶습니다.**

| 결합 | 연산자 | 의미 |
|---|---|---|
| AND | `&` | 모든 조건을 동시에 만족 |
| OR | `|` | 하나라도 만족 |
| NOT | `~` | 조건을 반대로(부정) |

**AND (`&`)** — 둘 다 만족
```python
# 현재가 10만 이상 그리고 거래량 50만 이상
df[(df['현재가'] >= 100000) & (df['거래량'] >= 500000)]
```
```
       종목명     현재가     거래량
1   SK하이닉스  120000  800000
2    NAVER  380000  500000
3      카카오  135000  600000
...
```

**OR (`|`)** — 하나라도 만족
```python
# 현재가 10만 이상 이거나 거래량 50만 이상
df[(df['현재가'] >= 100000) | (df['거래량'] >= 500000)]
```

**NOT (`~`)** — 조건을 뒤집기
```python
df[~(df['지역'] == '서울')]      # 서울이 "아닌" 종목 (df['지역'] != '서울' 와 동일)
```

**혼합** — 괄호로 우선순위를 명확히
```python
# 지역이 성남 이거나, (현재가 10만 이상 그리고 거래량 50만 이상)
df[(df['지역'] == '성남') | ((df['현재가'] >= 100000) & (df['거래량'] >= 500000))]
```

> ⚠️ **가장 흔한 두 가지 실수**
> 1. `and`/`or`를 쓰면 오류(`ValueError`)가 납니다. 반드시 `&`/`|`.
> 2. 괄호를 빼면 연산자 우선순위 때문에 엉뚱한 결과가 됩니다. **조건마다 `( )` 필수**.

### 2-3. `loc[]` — 조건과 열을 동시에

**개념**: `df[조건]`은 모든 열을 가져옵니다. **조건을 만족하는 행 중 특정 열만** 보려면 `loc[조건, 열목록]`을 씁니다.

**문법**
```python
df.loc[행조건, 열이름목록]
```

```python
# 현재가 20만 이상인 종목의 '종목명','현재가'만
df.loc[df['현재가'] >= 200000, ['종목명', '현재가']]
```
```
     종목명     현재가
2  NAVER  380000
4   LG화학  800000
5    현대차  200000
...
```

**복잡한 조건은 변수로** 빼면 읽기 쉽습니다.
```python
cond1 = (df['현재가'] >= 200000)
cond2 = (df['거래량'] >= 500000)
df.loc[cond1 & cond2, ['종목명', '현재가', '거래량']]
```

> 💡 조건이 길어질수록 `cond1`, `cond2`처럼 **이름을 붙여 조립**하면 실수가 줄고 가독성이 좋아집니다.

## 3. 자주 쓰는 필터 함수

비교 연산자만으로 불편한 경우를 위한 전용 메소드들입니다.

### 3-1. `isin()` — 목록 중 하나라도 일치
**개념**: 여러 값 중 하나에 해당하는 행을 한 번에 고릅니다. `==`를 여러 번 `|`로 잇는 것보다 깔끔합니다.

**문법**: `df[df['열'].isin([값1, 값2, ...])]`
```python
df[df['지역'].isin(['서울', '성남'])]      # 서울 또는 성남 (16개)
```
> `df['지역']=='서울' | df['지역']=='성남'`와 같은 결과지만 훨씬 간결합니다.

### 3-2. `between()` — 두 값 사이(범위)
**개념**: 시작값~끝값 범위의 데이터를 고릅니다.

**문법 / 인수**: `df['열'].between(left, right, inclusive='both')`

| 인수 | 의미 | 기본값 |
|---|---|---|
| `left`, `right` | 시작·끝 값 | (필수) |
| `inclusive` | 경계 포함 여부 | `'both'`(양끝 포함) |

```python
df[df['현재가'].between(100000, 300000)]    # 10만~30만 원 (양끝 포함, 8개)
```

### 3-3. `notna()` / `isnull()` — 결측치 필터
**개념**: 빈 값(NaN, 결측치)을 기준으로 거릅니다.
- `notna()`: 값이 **있는** 행 (결측 아님)
- `isnull()`(=`isna()`): 값이 **비어 있는** 행

```python
df[df['현재가'].notna()]     # 현재가가 있는 행만
df[df['현재가'].isnull()]    # 현재가가 비어 있는 행만 (결측 점검용)
```
> 📊 결측치를 "거르는" 것은 Part 5 전처리의 핵심입니다. 여기선 필터 도구로 먼저 만나봅니다.

### 3-4. `str.contains()` — 특정 문자열 포함
**개념**: 문자열 열에서 **특정 단어를 포함**한 행을 고릅니다. `.str` 접근자를 거쳐야 문자열 메소드를 쓸 수 있습니다.

**문법**: `df[df['열'].str.contains('찾을문자열')]`
```python
df[df['종목명'].str.contains('삼성')]      # 이름에 '삼성'이 든 종목
```
```
         종목명     현재가
0       삼성전자   70000
11  삼성바이오로직스  800000
12     삼성SDI  200000
19      삼성화재  160000
```
> ⚠️ 문자열 열에 결측치가 있으면 오류가 날 수 있어, 실무에서는 `na=False`(`.str.contains('삼성', na=False)`)를 함께 주기도 합니다.

## 4. 데이터 분석 프로세스에서의 활용 (필터 + 정렬 조합)

실전 분석은 **"필터로 좁히고 → 정렬로 줄 세우는"** 패턴의 반복입니다.

```python
# 예: 거래량 40만 이상인 종목을, 현재가 높은 순으로
관심 = df[df['거래량'] >= 400000]                 # ① 필터
관심 = 관심.sort_values(by='현재가', ascending=False)  # ② 정렬
관심[['종목명', '현재가', '거래량']].head(5)            # ③ 필요한 열·상위만
```

조건과 정렬을 바꿔가며 "현재가 상위 종목", "특정 지역의 고거래량 종목" 등 **수많은 질문에 즉시 답**할 수 있습니다. 이 패턴이 이후 모든 분석(집계·시각화)의 입력 데이터를 만듭니다.

## 5. 자주 하는 실수 체크리스트

- [ ] 복합 조건에서 `and`/`or` 대신 **`&`/`|`** 를 썼는가
- [ ] 각 조건을 **괄호 `( )`** 로 감쌌는가
- [ ] `sort_values`는 결과를 변수로 받거나 `inplace=True`를 줬는가(안 그러면 원본 안 바뀜)
- [ ] `sort_values`(값)와 `sort_index`(이름표)를 혼동하지 않았는가
- [ ] `str.contains`는 문자열 열에만 쓰고, 결측 있으면 `na=False`를 고려했는가
- [ ] `isin`에는 **리스트**를 넣었는가(`isin('서울')` X → 문자 하나하나로 인식)

---

## 6. 핵심 요약

1. 정렬: `sort_values(by=..., ascending=...)`(값 기준), `sort_index()`(이름표 기준). 여러 열·방향은 리스트로.
2. 필터의 원리: **조건식 → 불리언 Series → `df[불리언]`** 이 True인 행만 선택.
3. 복합 조건: `&`(AND) · `|`(OR) · `~`(NOT), 각 조건은 **괄호 필수**.
4. `loc[조건, [열]]` 로 행 조건과 열 선택을 동시에.
5. 전용 필터: `isin`(목록), `between`(범위), `notna`/`isnull`(결측), `str.contains`(문자 포함).
6. 실전은 **필터 → 정렬 → 상위 N** 패턴의 반복.
