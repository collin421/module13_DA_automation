## 4. 코드 실행 검증 (★필수 — 샌드박스에서 실제 실행)

> 문서의 **모든 핵심 코드 스니펫**을 샌드박스에서 실행해, 문서에 적은 **예상 출력과 실제 출력이 일치**하는지 확인한다.

검증 절차:
1. 문서 예제를 모은 검증 스크립트를 작성 (`/tmp` 또는 outputs에)
2. `pip install pandas numpy --break-system-packages` (필요 시)
3. 실행 → 출력 캡처
4. 문서의 "예상 출력"과 대조, 불일치하면 문서 수정
5. 시그니처 의심 시 `help(pd.함수)` 또는 `inspect.signature`로 인수·기본값 확인

- [ ] 모든 예제가 오류 없이 실행되는가
- [ ] 문서의 예상 출력 = 실제 출력인가 (숫자/형태)
- [ ] 인수 기본값을 `inspect.signature` 등으로 1회 이상 교차 확인했는가
