import pandas as pd

## 0. 들어가며 — 현실의 데이터는 깨끗하지 않다

교과서 데이터와 달리 실제 데이터에는 거의 항상 두 가지 문제가 있습니다.

- **결측치(missing value)**: 값이 비어 있음(`NaN`). 설문 미응답, 시스템 누락 등.
- **이상치(outlier)**: 비정상적으로 튀는 값. 입력 오류(나이 350), 측정 오류 등.

이를 그대로 두면 평균·분산이 왜곡되고, 잘못된 의사결정으로 이어집니다. **분석 전에 데이터를 "청소"하는 과정**이 전처리(preprocessing)이며, 실무 분석 시간의 절반 이상을 차지합니다.

> 📊 **분석 프로세스상 위치**: `[Part 2] 탐색에서 결측·이상 발견 → [Part 5] 전처리(지금) → [Part 6~] 집계·결합`. 탐색(`info`, `describe`)에서 찾은 문제를 여기서 고칩니다.

## 1. 결측치 확인 — `isnull()` / `isna()`

**개념**: 각 칸이 비어 있는지(`NaN`인지) True/False로 알려줍니다. `isnull()`과 `isna()`는 **완전히 같은** 메소드입니다(이름만 다름).

**원리**: 결과는 원본과 같은 크기의 True/False 표입니다. 여기에 `.sum()`을 붙이면 True를 1로 세어 **열별 결측 개수**가 나옵니다.

```python
df.isnull()              # 전체를 True/False로 (큼)
df.isnull().sum()        # 열별 결측 개수 (가장 많이 씀)
```
```
Customer_Type       2
Age              6972
Credit_Rank      8781
Bank             2759
...
dtype: int64
```
```python
df.isnull().sum().sum()  # 전체 결측 총 개수
```
```
18518
```

**특정 열의 결측 행 보기** — 불리언 인덱싱과 결합
```python
df['Age'].isnull().sum()        # 6972
df.loc[df['Age'].isnull()]      # Age가 빈 행만 추출
```

> 💡 `isnull().sum()`은 전처리의 **출발점**입니다. "어느 열에 결측이 몇 개인지" 먼저 파악해야 처리 전략을 정할 수 있습니다.

---

## 2. 결측치 처리 ① — 삭제: `dropna()`

**개념**: 결측치가 있는 **행(또는 열)을 통째로 삭제**합니다.

**원리**: 기본은 "결측이 **하나라도** 있는 행"을 모두 지웁니다. 데이터가 많고 결측이 적을 때 적합합니다.

**문법 / 인수**
```python
df.dropna(axis=0, how='any', subset=None, inplace=False)
```

| 인수 | 의미 | 기본값 |
|---|---|---|
| `axis` | `0`=행 삭제, `1`=열 삭제 | `0` |
| `how` | `'any'`(하나라도 결측) / `'all'`(전부 결측) | `'any'` |
| `subset` | 특정 열만 기준으로 | `None`(전체) |
| `inplace` | 원본에 바로 적용 | `False` |

```python
df_cleaned = df.dropna()           # 결측 있는 모든 행 제거
len(df_cleaned)                    # 40647  (원본 51301 → 1만여 행 손실)
```

> ⚠️ `dropna()`는 간단하지만 **데이터 손실이 큽니다**. 위 예에서 결측 때문에 약 21%(약 1만 행)가 사라졌습니다. 결측이 많은 열이 있으면 그 열만 `drop`하거나, 삭제 대신 **대체**(다음 절)를 고려해야 합니다.

특정 열만 기준으로 삭제하려면:
```python
df.dropna(subset=['Age'])          # Age가 빈 행만 제거
```

## 3. 결측치 처리 ② — 대체: `fillna()`

**개념**: 결측치를 **특정 값으로 채웁니다**. 보통 그 열의 **평균·중앙값·최빈값** 같은 대표값을 씁니다.

**문법**
```python
df['열'].fillna(value, inplace=False)
```

**평균으로 대체**
```python
df['Credit_Rank(mean)'] = df['Credit_Rank'].fillna(df['Credit_Rank'].mean())
```

**중앙값으로 대체**
```python
df['Credit_Rank(median)'] = df['Credit_Rank'].fillna(df['Credit_Rank'].median())
```

> 💡 새 열(`Credit_Rank(mean)`)에 담으면 원본을 보존하면서 결과를 비교할 수 있습니다.

### 평균 vs 중앙값 — 무엇으로 채울까?

| 상황 | 권장 대체값 | 이유 |
|---|---|---|
| 이상치가 적고 분포가 안정적 | **평균(mean)** | 분포를 유지 |
| 이상치가 많거나 분포가 치우침 | **중앙값(median)** | 이상치에 흔들리지 않음 |

**변동성 판단 — 변동계수(CV)**: `CV = 표준편차 / 평균 × 100`. **CV ≥ 30%면 변동성이 큼** → 중앙값이 안전합니다.

> 📊 `Credit_Rank`는 평균 약 3.43, 중앙값 3.0입니다. 둘이 비슷하면 무엇으로 채워도 무방하지만, 차이가 크면 분포가 치우쳤다는 뜻이라 중앙값을 택합니다.

결측이 너무 많은 열은 채우기보다 **열 자체를 삭제**하기도 합니다.
```python
df2 = df.drop(columns='Credit_Rank')      # 결측 많은 열 제거
```

---

## 4. 결측치 처리 ③ — 앞뒤 값으로 채우기: `ffill()` / `bfill()`

**개념**: 시계열(날짜순) 데이터처럼 **연속성이 중요한** 경우, 바로 앞이나 뒤의 값으로 결측을 채웁니다.

- `ffill()` (forward fill): **앞의 값**으로 채움
- `bfill()` (backward fill): **뒤의 값**으로 채움

```python
df = pd.read_csv('04_Stock_data02.csv')   # 주가 시계열(결측 포함)

df_ffill = df.ffill()     # 앞 값으로 채우기 (전일 가격 유지)
df_bfill = df.bfill()     # 뒤 값으로 채우기
```

> ⚠️ **버전 주의**: 예전에는 `df.fillna(method='ffill')`로 썼지만, 최신 판다스(2.x)에서 이 방식은 **사라질 예정(deprecated)** 입니다. 이제는 **`df.ffill()`, `df.bfill()`** 를 쓰세요.

> 📊 주가·기온처럼 "직전 값과 이어지는" 데이터엔 평균 대체보다 **앞/뒤 값 채우기**가 자연스럽습니다.

---

## 5. 이상치(outlier)란?

**개념**: 일반적인 패턴에서 **극단적으로 벗어난 값**. 발생 원인:

- **입력 오류**: 35를 350으로 잘못 입력
- **측정 오류**: 고장난 기기의 잘못된 기록
- **처리 오류**: 단위 변환 실수 등

**왜 문제인가**: 평균이 크게 휘둘립니다. 예) `2,1,3,4,5`의 평균은 3이지만, `2,1,3,4,1000`의 평균은 약 200 — 값 하나가 전체를 왜곡합니다.

---

## 6. 이상치 처리 ① — 조건으로 제거·대체·결측화

이상치가 명확하면(예: 음수 수량) 조건 필터로 직접 다룹니다.

**제거** — 조건의 반대(`~`)만 남기기
```python
이상치 = df['수량'] < 0          # 말이 안 되는 음수 수량
df2 = df.loc[~이상치]            # 정상 값만 남김
```

**대체** — 이상치 위치에 값 할당
```python
df['수량(보정)'] = df['수량']
df.loc[df['수량'] < 0, '수량(보정)'] = 1     # 음수를 1로 대체
```

**결측치로 바꾸기** — 나중에 일괄 처리하려고 `NaN`으로
```python
df.loc[df['상품번호'] == 999999, '상품번호'] = np.nan   # 오류코드를 결측으로
```

> ⚠️ **행 삭제의 함정**: 이상치가 있는 행을 통째로 지우면 **같은 행의 멀쩡한 다른 값들도 함께 사라집니다.** 그래서 제거보다 **대체·결측화**를 택하는 경우가 많습니다.

> 💡 `df.loc[조건, '열'] = 값` 은 "조건을 만족하는 행의 특정 열만 골라 값을 바꾸는" 매우 자주 쓰는 패턴입니다.

## 7. 이상치 탐지 — 통계적 방법

이상치가 눈에 안 보일 때는 통계로 경계를 정합니다. 학생 성적 데이터로 살펴봅니다.

```python
df = pd.read_csv('pandas_05_DDA(student_score).csv', index_col=0)
df.columns = ['수학', '읽기', '쓰기', '학습시간', '나이']
```

### 7-1. 시각적 확인 — `boxplot()` / `hist()`
**개념**: 그림으로 분포와 튀는 값을 한눈에 봅니다. 박스플롯의 수염(whisker) 밖 점들이 이상치 후보입니다.
```python
import matplotlib.pyplot as plt
df.boxplot()      # 상자그림: 수염 밖 점 = 이상치 후보
df.hist(bins=20)  # 히스토그램: 분포 모양
plt.show()
```

### 7-2. IQR 방법 (가장 널리 씀)
**개념**: 가운데 50% 범위(IQR)를 기준으로 경계를 정합니다.

**원리·공식**
- Q1 = 1사분위(하위 25%), Q3 = 3사분위(상위 25%)
- **IQR = Q3 − Q1**
- **하한선 = Q1 − 1.5 × IQR**, **상한선 = Q3 + 1.5 × IQR**
- 이 범위를 벗어나면 이상치로 판단

**사용법**
```python
Q1 = df['수학'].quantile(0.25)     # 60.69
Q3 = df['수학'].quantile(0.75)     # 83.38
IQR = Q3 - Q1                      # 22.68

하한선 = Q1 - 1.5 * IQR            # 26.67
상한선 = Q3 + 1.5 * IQR            # 117.40

# 이상치 확인
이상치 = df.loc[(df['수학'] < 하한선) | (df['수학'] > 상한선), '수학']
이상치
```
```
123.0, 200.0, 150.0, 130.0     # 100점 만점인데 100 초과 → 입력 오류!
```

**이상치 제거** (정상 범위만 남기기)
```python
df_cleaned = df.loc[(df['수학'] >= 하한선) & (df['수학'] <= 상한선)]
df_cleaned.shape      # (98, 5)  ← 원본 (102, 5)에서 이상치 4개 제거
```

### 7-3. 표준편차 방법 (±3σ)
**개념**: 정규분포에서 평균 ± 3×표준편차를 벗어나면 이상치로 봅니다(약 99.7% 밖).

```python
평균 = df['읽기'].mean()        # 65.82
표준편차 = df['읽기'].std()      # 13.68

하한선 = 평균 - 3 * 표준편차      # 24.79
상한선 = 평균 + 3 * 표준편차      # 106.86

df_reading = df[(df['읽기'] >= 하한선) & (df['읽기'] <= 상한선)]
```

| 방법 | 경계 | 특징 |
|---|---|---|
| **IQR** | Q1−1.5·IQR ~ Q3+1.5·IQR | 분포 모양에 덜 민감, 가장 보편적 |
| **표준편차(±3σ)** | 평균±3·표준편차 | 정규분포 가정에 적합 |

> 📊 어떤 방법이든 핵심은 **"경계를 정하고 → 조건 필터로 골라낸다"** 입니다. 경계 계산만 다를 뿐, 처리(제거·대체)는 Part 3의 필터링과 똑같습니다.

## 8. 데이터 분석 프로세스에서의 활용 (전처리 파이프라인)

```python
# ① 결측 파악
df.isnull().sum()

# ② 결측 처리 — 적으면 삭제, 많으면 대체
df['Age'] = df['Age'].fillna(df['Age'].median())     # 중앙값 대체
df = df.dropna(subset=['Bank'])                       # 핵심 열 결측은 삭제

# ③ 이상치 탐지·처리 (IQR)
Q1, Q3 = df['Amount_Month'].quantile([0.25, 0.75])
IQR = Q3 - Q1
df = df[(df['Amount_Month'] >= Q1-1.5*IQR) & (df['Amount_Month'] <= Q3+1.5*IQR)]
```

이렇게 정제된 데이터라야 다음 단계(집계·결합·시각화)의 결과가 신뢰할 수 있습니다. **"쓰레기를 넣으면 쓰레기가 나온다"** — 전처리가 분석 품질을 좌우합니다.

---

## 9. 자주 하는 실수 체크리스트

- [ ] 처리 전에 `isnull().sum()`으로 **결측 위치·규모**를 먼저 확인했는가
- [ ] `dropna()`로 데이터가 과도하게 줄지 않았는지 행 수를 비교했는가
- [ ] 이상치 많은 열은 평균 대신 **중앙값**으로 채웠는가
- [ ] 시계열은 평균이 아니라 **`ffill`/`bfill`** 을 고려했는가
- [ ] `fillna(method='ffill')`(구버전) 대신 **`ffill()`** 를 썼는가
- [ ] 이상치 처리 시 행 통째 삭제로 **다른 열의 정상값까지 잃지** 않았는가
- [ ] `fillna`/`dropna` 결과를 변수에 받거나 `inplace`를 줬는가(안 그러면 원본 유지)

---

## 10. 핵심 요약

1. 결측 확인: `isnull().sum()`(열별), `.sum().sum()`(전체).
2. 결측 처리: 삭제 `dropna()`, 대체 `fillna()`(평균/중앙값), 시계열 `ffill()`/`bfill()`.
3. 평균 vs 중앙값: 이상치 많으면(변동계수 CV↑) **중앙값**.
4. 이상치 처리: 조건 필터로 제거(`~`)·대체(`loc[조건,열]=값`)·결측화(`np.nan`).
5. 이상치 탐지: **IQR**(Q1−1.5·IQR ~ Q3+1.5·IQR), **표준편차**(평균±3σ), 시각화(`boxplot`·`hist`).
6. 전처리는 **결측 → 이상치** 순으로, 데이터 손실을 최소화하며 진행한다.
