# Part 8 · 피벗테이블 — pivot_table로 요약하기

> **이 파트의 목표**
> - 엑셀 피벗처럼 데이터를 **기준별로 요약·집계**하는 `pivot_table`을 익힌다.
> - `index`·`values`·`columns`·`aggfunc`·`margins` 인수의 역할을 이해한다.
> - 행(index)과 열(columns)을 자유롭게 배치해 **교차표(cross table)** 를 만든다.
>
> **선행 지식**: Part 6(`groupby`, `agg`, `to_datetime`·`.dt`), Part 4(`to_excel`).

예제는 제품 판매 데이터 `08_pivot_제품.csv`와 렌탈 계약 데이터 `01_Contract_Data.csv`를 사용합니다.

```python
import pandas as pd
df = pd.read_csv('08_pivot_제품.csv', index_col=0)   # 지역·제품·분기·판매량·매출액·할인율
```

---

## 0. 들어가며 — 엑셀 피벗을 코드로

데이터가 수천 줄이면 개별 행은 의미가 없습니다. **"제품별 총 판매량", "분기별·지역별 매출"** 처럼 기준에 따라 묶어 요약해야 패턴이 보입니다.

엑셀을 써 봤다면 **피벗 테이블(Pivot Table)** 을 알 것입니다. 행에 제품, 열에 분기, 값에 판매량을 끌어다 놓으면 표가 만들어지는 그 기능을, 판다스에서는 `pivot_table` 한 줄로 합니다.

> 📊 **분석 프로세스상 위치**: `[Part 7] 결합 → [Part 8] 요약·집계(지금) → [Part 9] 구조화`. Part 6의 `groupby`를 **2차원(행×열) 표** 형태로 확장한 것이 피벗테이블입니다.

---

## 1. `pivot_table()` 기본 — index와 values

**개념**: 어떤 기준(`index`)으로 묶어서, 어떤 값(`values`)을 요약할지 지정하면 요약표가 나옵니다.

**원리**: 같은 `index` 값을 가진 행들을 모아 `values`를 집계합니다. **집계 기본값은 평균(`mean`)** 입니다. (groupby와 같은 분리-적용-결합 원리)

**문법 / 인수**
```python
pd.pivot_table(data, index=None, values=None, columns=None, aggfunc='mean', margins=False)
```

| 인수 | 의미 | 기본값 |
|---|---|---|
| `data` | 대상 데이터프레임 | (필수) |
| `index` | 그룹화할 **행** 기준 열 | None |
| `values` | 집계할 값 열 | None |
| `columns` | 그룹화할 **열** 기준 | None |
| `aggfunc` | 집계 함수 | `'mean'` |
| `margins` | 행·열 총합 추가 | `False` |

**사용법** (기본 = 평균)
```python
pd.pivot_table(data=df, index='제품', values='판매량')
```
```
              판매량
제품
LG OLED TV  195.0
삼성 갤럭시 S21  132.5
애플 아이폰 12   257.5
```
> 제품별 **평균** 판매량입니다(aggfunc 미지정 → mean).

> 💡 `pd.pivot_table(df, ...)` 와 `df.pivot_table(...)` 는 같은 기능입니다. 데이터프레임 메소드 형태도 자주 씁니다.

---

## 2. `aggfunc` — 집계 방식 바꾸기

**개념**: 평균이 아니라 합계·개수·최대 등 다른 집계를 하려면 `aggfunc`를 지정합니다.

| `aggfunc` 값 | 집계 |
|---|---|
| `'mean'`(기본) | 평균 |
| `'sum'` | 합계 |
| `'count'` | 개수 |
| `'min'` / `'max'` | 최소 / 최대 |
| `'median'` | 중앙값 |
| `'std'` / `'var'` | 표준편차 / 분산 |
| `'nunique'` | 고유값 개수 |

```python
pd.pivot_table(data=df, index='제품', values='판매량', aggfunc='sum')
```
```
             판매량
제품
LG OLED TV  1560
삼성 갤럭시 S21  1060
애플 아이폰 12   2060
```

---

## 3. 다중 집계 — 여러 값·여러 방식

**여러 값을 한 번에** — `values`에 리스트
```python
pd.pivot_table(data=df, index='제품', values=['판매량', '매출액'], aggfunc='sum')
```

**값마다 다른 집계** — `aggfunc`에 딕셔너리 `{열: 함수}`
```python
pd.pivot_table(data=df, index='제품',
               values=['판매량', '매출액'],
               aggfunc={'판매량': 'sum', '매출액': 'mean'})   # 판매량은 합, 매출액은 평균
```

> 💡 이 부분은 Part 6 `agg`의 딕셔너리 사용법과 같은 원리입니다.

---

## 4. 다중 인덱스 — 여러 기준으로 세분화

**개념**: `index`에 여러 열을 리스트로 주면, 그 조합별로 더 잘게 나눠 집계합니다.

```python
pd.pivot_table(data=df, index=['제품', '지역'], values=['판매량', '매출액'], aggfunc='sum')
```
> "제품 × 지역" 조합별 합계가 계층 구조(다중 인덱스)로 나옵니다. 예: 삼성 갤럭시 S21–서울, 삼성 갤럭시 S21–부산 …

---

## 5. `columns` — 행을 열로 펼치기 (교차표)

**개념**: `columns`에 열을 지정하면 그 값들이 **가로 방향 열**이 됩니다. index(세로) × columns(가로)의 **교차표**가 만들어집니다.

```python
pd.pivot_table(data=df, index='제품', values='판매량', columns='분기', aggfunc='sum')
```
```
분기            Q1   Q2   Q3   Q4
제품
LG OLED TV   450  330  370  410
삼성 갤럭시 S21   250  230  270  310
애플 아이폰 12    650  430  470  510
```
> 세로축은 제품, 가로축은 분기, 칸의 값은 판매량 합계. 엑셀 피벗의 전형적인 모습입니다.

> 📊 `index`(행)와 `columns`(열)에 무엇을 두느냐로 **보는 관점**이 바뀝니다. "제품×분기"로 보면 제품별 분기 추세가, "지역×제품"으로 보면 지역별 제품 비중이 드러납니다.

---

## 6. `margins` — 총합 추가

**개념**: `margins=True`를 주면 행·열의 **총합(All)** 이 자동으로 붙습니다. `margins_name`으로 이름을 바꿉니다.

```python
pd.pivot_table(data=df, index='제품', values='판매량', columns='분기',
               aggfunc='sum', margins=True, margins_name='총합')
```
```
분기            Q1    Q2    Q3    Q4    총합
제품
LG OLED TV   450   330   370   410  1560
삼성 갤럭시 S21   250   230   270   310  1060
애플 아이폰 12    650   430   470   510  2060
총합          1350   990  1110  1230  4680
```
> 맨 아래·오른쪽에 합계가 추가됩니다. 전체 4,680개가 한눈에 보입니다.

행 총합만 빼고 싶으면 `.drop('총합', axis=0)`(Part 1)으로 제거합니다.

---

## 7. groupby vs pivot_table

둘 다 그룹 집계지만 결과 모양이 다릅니다.

| 구분 | `groupby` | `pivot_table` |
|---|---|---|
| 결과 형태 | 보통 1차원(세로로 쌓임) | **2차원 표(행×열)** |
| 교차표(columns) | 직접 만들기 번거로움 | `columns`로 쉽게 |
| 총합 | 별도 계산 | `margins=True` |
| 기본 집계 | 지정 필요 | `mean` |

> 💡 "한 기준 요약"이면 groupby, "행×열 교차표 + 총합"이면 pivot_table이 편합니다. 내부 원리는 같습니다.

## 8. 실전 — 렌탈 데이터 요약과 증감 분석

대형 계약 데이터로 실무 요약을 만듭니다.

```python
df1 = pd.read_csv('01_Contract_Data.csv')
```

**채널별 월 매출 합계**
```python
df1.pivot_table(index='Channel', values='Amount_Month', aggfunc='sum')
```
```
Channel
영업방판       2384371860     ← 가장 큰 채널
홈쇼핑/방송     1156149900
대형마트A       458402160
...
```

**연도별 제품 매출 + 증감율** (Part 6 날짜 + 새 열 계산)
```python
df1['연도'] = pd.to_datetime(df1['Datetime']).dt.year

df2 = df1.pivot_table(index='Product_Type', values='Amount_Month',
                      columns='연도', aggfunc='sum')
df2['증감액'] = df2[2020] - df2[2019]
df2['증감율'] = (df2['증감액'] / df2[2019]) * 100
df2.head(2)
```
```
연도                  2019        2020          증감액     증감율
Product_Type
DES-1         2946278610   748837116  -2197441494  -74.58
DES-2          631877970   155779320   -476098650  -75.35
```
> 피벗 결과에 **새 열을 더해** 전년 대비 증감을 계산했습니다. 요약표가 그대로 분석으로 이어집니다.

**엑셀로 저장** (Part 4)
```python
df1.pivot_table(index='Sales_Type', columns=['연도', '월'],
                values='Amount_Month', aggfunc='sum').to_excel('연도별월별_렌탈비용.xlsx')
```

## 9. 데이터 분석 프로세스에서의 활용

```python
# ① 날짜 축 만들기 (Part 6)
df['연도'] = pd.to_datetime(df['날짜']).dt.year

# ② 교차표로 요약 (행=제품, 열=연도, 값=매출 합계)
표 = df.pivot_table(index='제품', columns='연도', values='매출', aggfunc='sum', margins=True)

# ③ 요약표에 파생 지표 추가
표['증감율'] = (표[2020] - 표[2019]) / 표[2019] * 100

# ④ 보고용 저장
표.to_excel('연도별_제품매출.xlsx')
```

피벗테이블은 **"불러오기 → 가공 → 결합"** 을 거친 데이터를 **최종 보고서 형태**로 요약하는 단계입니다. 실무 리포트의 절반 이상이 피벗 형태입니다.

---

## 10. 자주 하는 실수 체크리스트

- [ ] `aggfunc`를 안 주면 **평균(mean)** 이 기본임을 인지했는가(합계를 원하면 `'sum'`)
- [ ] `index`(세로)와 `columns`(가로)의 역할을 구분했는가
- [ ] 여러 값은 `values=[...]` 리스트, 값별 집계는 `aggfunc={...}` 딕셔너리로 줬는가
- [ ] `margins=True`로 총합을 넣었고, 이름은 `margins_name`으로 지정했는가
- [ ] `columns`로 만든 교차표에서 결측(특정 조합이 없을 때 NaN)을 확인했는가
- [ ] 피벗 결과의 열 이름(예: 연도 `2019`)이 숫자인지 문자열인지 확인하고 접근했는가

---

## 11. 핵심 요약

1. `pivot_table(index=, values=, columns=, aggfunc=, margins=)` 로 기준별 요약표를 만든다.
2. **`index`=세로 기준, `columns`=가로 기준, `values`=집계할 값**.
3. `aggfunc` 기본은 **평균**. 합계 등은 `'sum'` 지정. 값별 집계는 딕셔너리.
4. `columns`를 주면 **교차표**, `margins=True`면 **총합**이 붙는다.
5. groupby와 원리는 같지만, 피벗은 **2차원 표 + 총합**에 강하다.
6. 피벗 결과에 새 열(증감율 등)을 더해 곧바로 분석·보고로 잇는다.
