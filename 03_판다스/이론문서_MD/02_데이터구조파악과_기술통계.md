> - 데이터를 불러온 직후 **가장 먼저 확인해야 할 것**(크기·열·타입·결측)을 안다.
> - **숫자형 데이터**의 대표값·산포도·분포를 구하는 메소드를 익힌다(`mean`, `median`, `std`, `quantile`, `describe`).

> **선행 지식**: Part 1(Series·DataFrame, `read_csv`, 열 선택). 통계 용어는 이 문서에서 모두 풀어서 설명함.

이 파트의 모든 예제는 렌탈·멤버십 계약 데이터 `01_Contract_Data.csv`(약 5만 건)를 사용합니다.

```python
import pandas as pd
df = pd.read_csv('01_Contract_Data.csv')
```

## 0. 들어가며 — 왜 "구조 파악"부터 하는가?

데이터를 받자마자 분석부터 하면 거의 반드시 사고가 납니다. 의사가 환자를 보면 먼저 키·몸무게·체온을 재듯, 데이터 분석가도 **데이터의 모양과 성질을 먼저 확인**합니다. 이 과정을 **DDA(기술적 데이터 분석, Descriptive Data Analysis)** 또는 EDA라고 부릅니다.

구조를 먼저 파악하면:

- **적합한 분석 방법을 고른다** — 숫자형은 평균·표준편차, 범주형은 빈도수. 데이터 타입에 따라 쓸 수 있는 통계가 다릅니다.
- **오류를 예방한다** — 숫자처럼 보이지만 문자로 저장된 열, 빈 값(결측치)을 미리 발견합니다.
- **전처리 시간을 아낀다** — 무엇을 고쳐야 할지 먼저 보입니다.

> 📊 **분석 프로세스상 위치**: `[Part 1] 불러오기 → [Part 2] 구조·통계 파악(지금) → [Part 3~6] 정제 → [Part 7~9] 결합·요약`

### 먼저 알아둘 개념: 데이터 타입 2종류

| 분류 | 판다스 dtype | 예 | 무엇을 보나 |
|---|---|---|---|
| **연속형(숫자)** | `int64`(정수), `float64`(실수) | 나이, 금액, 기간 | 평균·표준편차·분포 |
| **범주형(문자)** | `object` | 성별, 은행명, 계약유형 | 고유값·빈도수 |

이 구분이 이 파트 전체의 뼈대입니다. **숫자형이냐 범주형이냐에 따라 보는 통계가 완전히 다릅니다.**

## 1. 데이터를 불러오면 가장 먼저 확인할 것

### 1-1. `.columns` / `.index` / `.shape` — 크기와 뼈대

이 셋은 **메소드가 아니라 속성(attribute)** 입니다. 그래서 **괄호 `()`를 붙이지 않습니다.**

**`df.columns`** — 열(항목) 이름 목록
```python
df.columns
```
```
Index(['Index', 'Member_ID', 'Sales_Type', 'Contract_Type', 'Channel',
       'Datetime', 'Term', 'Payment_Type', ... 'Bank'], dtype='object')
```

**`df.index`** — 행의 범위(개수)
```python
df.index
```
```
RangeIndex(start=0, stop=51301, step=1)   # 0~51300, 즉 51,301행
```

**`df.shape`** — (행 개수, 열 개수)를 튜플로 반환
```python
df.shape
```
```
(51301, 20)    # 5만 1,301행 × 20열
```

> 💡 `shape`는 데이터 크기를 한눈에 보는 가장 빠른 방법입니다. `df.shape[0]`은 행 수, `df.shape[1]`은 열 수.

### 1-2. `info()` — 구조·타입·결측을 한 번에

**개념**: 각 열의 **데이터 타입, 결측이 아닌 값의 개수(Non-Null Count), 메모리 사용량**을 한 번에 보여주는 가장 중요한 진단 메소드입니다.

**원리**: 전체 행 수와 각 열의 "Non-Null" 개수를 비교하면 **결측치(빈 값)의 존재**를 바로 알 수 있습니다.

**문법**
```python
df.info()
```

**사용법 / 출력(요약)**
```python
df.info()
```
```
<class 'pandas.core.frame.DataFrame'>
RangeIndex: 51301 entries, 0 to 51300

 #   Column        Non-Null Count  Dtype
---  ------        --------------  -----
 6   Term          51301 non-null  int64
 9   Amount_Month  51301 non-null  int64
 11  Age           44329 non-null  float64   ← 51301보다 적음 = 결측 있음!
 19  Bank          48542 non-null  object    ← 결측 있음!
dtypes: float64(2), int64(5), object(13)
```

> ⚠️ **핵심 읽기 포인트**: 전체 51,301행인데 `Age`는 44,329개, `Bank`는 48,542개만 값이 있습니다. 차이만큼이 **결측치**입니다. 이 발견이 Part 5(전처리)로 이어집니다.

### 1-3. `head()` / `tail()` — 실제 값 눈으로 보기

| 메소드 | 의미 | 기본값 |
|---|---|---|
| `df.head(n)` | 상위 n행 | n=5 |
| `df.tail(n)` | 하위 n행 | n=5 |

```python
df.head()    # 위에서 5행 — 데이터가 어떻게 생겼는지 확인
df.tail(3)   # 아래에서 3행 — 끝부분도 정상인지 확인
```

> 📊 `info()`로 구조를, `head()`로 실제 값을 확인하는 두 동작은 **데이터를 불러온 직후의 기본 루틴**입니다.

## 2. 숫자형 데이터의 기술 통계

숫자 열 하나(예: 월 납입액 `Amount_Month`)를 골라 통계를 냅니다. 열 하나는 Series이고, Series는 통계 메소드를 가집니다.

```python
df['Amount_Month']    # 월 납입액 열 (Series)
```

### 2-1. 대표값 — 데이터의 "중심"

데이터를 대표하는 가운데 값입니다. 세 가지가 있습니다.

#### `mean()` — 평균
**개념**: 모든 값을 더해 개수로 나눈 산술 평균.
```python
df['Amount_Month'].mean()
```
```
93994.97...   # 평균 월 납입액 약 9.4만 원
```

#### `median()` — 중앙값
**개념**: 값을 크기순으로 줄 세웠을 때 **정확히 가운데** 있는 값.
**원리**: 평균은 극단적으로 큰 값(이상치) 하나에 휘둘리지만, 중앙값은 흔들리지 않습니다. 그래서 소득·집값처럼 한쪽으로 치우친 데이터는 중앙값이 더 정확한 "보통"을 보여줍니다.
```python
df['Amount_Month'].median()
```
```
96900.0
```

#### `mode()` — 최빈값
**개념**: 가장 **자주 등장하는** 값. 범주형에서 특히 유용하지만 숫자형에도 씁니다.
**원리**: 여러 값이 공동 1위일 수 있어, 결과는 **Series로 반환**됩니다(스칼라 아님).
```python
df['Amount_Month'].mode()
```
```
0    96900
Name: Amount_Month, dtype: int64    # 9.69만 원이 가장 흔한 납입액
```

#### `sum()` — 합계 (참고)
```python
df['Amount_Month'].sum()
```
```
4822036176    # 전체 월 납입액 총합
```

> ⚠️ **평균 vs 중앙값**: 여기선 평균(93,995) < 중앙값(96,900)입니다. 평균이 더 낮다는 건 **유난히 작은 값들이 평균을 끌어내렸다**는 신호 — 분포가 한쪽으로 치우쳤다는 뜻입니다.

### 2-2. 산포도 — 데이터가 "얼마나 흩어졌나"

대표값만으로는 부족합니다. 같은 평균이라도 값들이 평균 근처에 몰려 있는지, 넓게 퍼졌는지가 다릅니다. 이 흩어짐을 재는 것이 산포도입니다.

#### `var()` — 분산(Variance)
**개념**: 각 값이 평균에서 떨어진 거리를 제곱해 평균낸 값. 클수록 넓게 퍼짐.
**인수**: `ddof`(기본 1=표본분산). `ddof=0`이면 모집단 분산.
```python
df['Amount_Month'].var()
```
```
234220496.23...
```

#### `std()` — 표준편차(Standard Deviation)
**개념**: 분산의 제곱근. **분산은 단위가 제곱이라 해석이 어렵지만, 표준편차는 원래 단위(원)로 돌아와** 직관적입니다.
```python
df['Amount_Month'].std()
```
```
15304.26...   # 납입액이 평균에서 평균적으로 ±1.5만 원가량 흩어져 있음
```

| 메소드 | 의미 | 핵심 인수 |
|---|---|---|
| `var()` | 분산(제곱 단위) | `ddof=1`(기본) |
| `std()` | 표준편차(원래 단위) | `ddof=1`(기본) |

> 💡 실무에서는 해석이 쉬운 **표준편차**를 주로 봅니다. "평균 ± 표준편차" 범위에 대부분의 데이터가 들어옵니다.

### 2-3. 범위와 분포 — `min`, `max`, `quantile`

#### `min()` / `max()` — 최소·최대
```python
df['Amount_Month'].min()   # 54603
df['Amount_Month'].max()   # 215700
범위 = df['Amount_Month'].max() - df['Amount_Month'].min()   # 161097
```

#### `quantile()` — 분위수
**개념**: 데이터를 크기순 정렬했을 때 특정 비율 위치의 값. `0.25`(25%, 1사분위 Q1), `0.5`(중앙값), `0.75`(3사분위 Q3).

**문법 / 인수**
```python
df['열'].quantile(q=0.5)   # q: 0~1 사이 비율 (리스트도 가능)
```

```python
q1 = df['Amount_Month'].quantile(0.25)   # 81900.0
q2 = df['Amount_Month'].quantile(0.50)   # 96900.0  (= 중앙값)
q3 = df['Amount_Month'].quantile(0.75)   # 98400.0
IQR = q3 - q1                            # 16500.0  (사분위 범위)
```

> 📊 **IQR(사분위 범위)** 는 가운데 50% 데이터가 퍼진 폭입니다. Part 5에서 **이상치 탐지**의 핵심 도구로 다시 등장합니다. (지금은 "분포를 보는 값" 정도로 기억)

### 2-4. `describe()` — 숫자 통계를 한 번에

**개념**: 위에서 따로따로 구한 통계(개수·평균·표준편차·최소·분위수·최대)를 **한 표로** 요약합니다. 숫자형 탐색의 핵심 메소드.

**문법**
```python
df.describe()              # 숫자형 열 전체 요약
df['Amount_Month'].describe()   # 특정 열만
```

**출력**
```python
df[['Term','Amount_Month','Age']].describe()
```
```
           Term  Amount_Month       Age
count  51301.00      51301.00  44329.00   ← 개수 (Age는 결측으로 적음)
mean      55.64      93994.97     50.02   ← 평균
std       12.01      15304.26     10.98   ← 표준편차
min       12.00      54603.00     25.00   ← 최소
25%       60.00      81900.00     42.00   ← Q1
50%       60.00      96900.00     49.00   ← 중앙값
75%       60.00      98400.00     57.00   ← Q3
max       60.00     215700.00    102.00   ← 최대
```

> ⚠️ `Age`의 `max`가 **102세**입니다. 현실적으로 의심스러운 값 — 이런 식으로 `describe()` 한 번에 **이상치 후보**도 발견됩니다.

## 3. 범주형 데이터의 탐색

성별·은행·계약유형 같은 문자(object) 열은 평균을 낼 수 없습니다. 대신 **어떤 항목이 있고(고유값), 각각 몇 개인지(빈도)** 를 봅니다.

### 3-1. `count()` — 값의 개수(결측 제외)
```python
df['Bank'].count()
```
```
48542    # 전체 51301 중 결측을 뺀 실제 값 개수
```

### 3-2. `unique()` / `nunique()` — 고유값과 그 개수
**개념**: `unique()`는 **중복을 제거한 고유 항목 목록**(배열), `nunique()`는 그 **개수**(숫자).
```python
df['Sales_Type'].unique()
```
```
array(['렌탈', '멤버십'], dtype=object)   # 판매유형은 2종류
```
```python
df['Bank'].nunique()    # 47  → 은행/카드사가 47개
```

> 💡 `unique()`는 "이 열에 어떤 값들이 들어있지?"를 확인할 때, `nunique()`는 "종류가 몇 개지?"를 셀 때 씁니다.

### 3-3. `value_counts()` — 빈도수(가장 많이 씀)
**개념**: 각 항목이 **몇 번 등장하는지** 세어 **많은 순으로 정렬**해 반환합니다.

**문법 / 인수**
```python
df['열'].value_counts(normalize=False, sort=True, ascending=False, dropna=True)
```

| 인수 | 의미 | 기본값 |
|---|---|---|
| `normalize` | 개수 대신 **비율(0~1)** 로 | `False` |
| `sort` | 빈도순 정렬 | `True` |
| `ascending` | 오름차순 | `False`(많은 순) |
| `dropna` | 결측 제외 | `True` |

**사용법**
```python
df['Bank'].value_counts()
```
```
롯데카드      9516
농협회원조합    6277
국민은행      6002
농협중앙회     3899
신한은행      3522
...
Name: count, dtype: int64
```

**상대 빈도(비율)** — `normalize=True`
```python
df['Bank'].value_counts(normalize=True)
```
```
롯데카드      0.1960    # 전체의 약 19.6%
농협회원조합    0.1293
국민은행      0.1236
...
```

> 📊 `value_counts()`는 범주형 분석에서 **가장 자주 쓰는 메소드**입니다. "어떤 결제수단이 가장 많은가", "어느 채널 비중이 큰가"를 한 줄로 답합니다.

### 3-4. `mode()` — 최빈값(범주형)
```python
df['Bank'].mode()
```
```
0    롯데카드
Name: Bank, dtype: object   # 가장 많이 쓰인 결제수단
```

### 3-5. `describe(include='object')` — 범주형 요약
**개념**: `describe()`는 기본적으로 숫자형만 요약하지만, `include='object'`를 주면 **문자형 열**을 요약합니다. 항목은 다릅니다.

| 항목 | 의미 |
|---|---|
| `count` | 값 개수 |
| `unique` | 고유값 개수 |
| `top` | 가장 많은 값 |
| `freq` | top의 빈도 |

```python
df['Bank'].describe()
```
```
count     48542
unique       47
top        롯데카드
freq       9516
Name: Bank, dtype: object
```
```python
df.describe(include='object')   # 모든 문자열 열을 한 번에
```
```
       Sales_Type   Bank Gender ...
count       51301  48542  51301
unique          2     47      2
top            렌탈   롯데카드     여자
freq        46483   9516  35602
```

## 4. 데이터 분석 프로세스에서의 활용 (한 사이클)

데이터를 받았을 때 실제로 이렇게 훑습니다.

```python
df = pd.read_csv('01_Contract_Data.csv')   # ① 불러오기

# ② 구조 파악
df.shape            # (51301, 20) — 크기
df.info()           # 타입 + 결측(Age, Bank에 결측 발견)
df.head()           # 실제 값 모양

# ③ 숫자형 탐색
df.describe()                       # 숫자 열 요약
df['Amount_Month'].mean()           # 평균 납입액
df['Amount_Month'].std()            # 변동성

# ④ 범주형 탐색
df['Sales_Type'].value_counts()     # 렌탈 vs 멤버십 비중
df['Bank'].value_counts(normalize=True)   # 결제수단 점유율
```

이 한 사이클로 "데이터 크기, 결측 위치, 숫자 분포, 범주 비중"을 모두 파악합니다. **여기서 발견한 결측·이상치가 다음 단계(정제)의 할 일 목록**이 됩니다.

## 5. 자주 하는 실수 체크리스트

- [ ] `.shape`, `.columns`, `.index`는 속성이라 **괄호를 안 붙인다**(`df.shape` O, `df.shape()` X)
- [ ] `.info()`, `.describe()` 등 메소드는 **괄호를 붙인다**
- [ ] `mode()`는 스칼라가 아니라 **Series**를 반환한다(값 하나가 필요하면 `.mode()[0]`)
- [ ] `describe()`는 기본이 숫자형만 — 문자열은 `include='object'` 필요
- [ ] `info()`의 Non-Null Count를 전체 행 수와 비교해 **결측을 확인**했는가
- [ ] 평균이 이상치에 약하다는 점을 의식하고 **중앙값과 함께** 봤는가

---

## 6. 핵심 요약

1. 데이터를 불러오면 **`shape` → `info` → `head`** 로 크기·타입·결측·모양을 먼저 본다.
2. 데이터 타입은 **연속형(숫자, int/float)** 과 **범주형(문자, object)** 으로 나뉘고, 보는 통계가 다르다.
3. 숫자형: 대표값(`mean`·`median`·`mode`), 산포도(`var`·`std`), 분포(`min`·`max`·`quantile`)를 **`describe()`로 한 번에**.
4. 범주형: `value_counts()`(빈도·비율), `unique()`/`nunique()`(고유값), `describe(include='object')`.
5. 평균은 이상치에 약하므로 **중앙값·분포와 함께** 해석한다.

### 미니 퀴즈
1. `df.shape`와 `df.info()` 중 괄호가 필요한 것은? (답: `info()` — 메소드. `shape`는 속성)
2. 어떤 결제수단이 가장 많이 쓰였는지 비율로 보려면? (답: `df['Bank'].value_counts(normalize=True)`)
3. 평균(93,995)이 중앙값(96,900)보다 낮다는 것은 무엇을 시사하는가? (답: 작은 값들이 평균을 끌어내림 = 분포가 한쪽으로 치우침)
