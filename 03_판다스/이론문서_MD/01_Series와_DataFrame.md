# Part 1 · Series와 DataFrame — 데이터를 담는 두 그릇

> **이 파트의 목표**
> - 판다스가 데이터를 담는 두 가지 구조 **Series(1차원)** 와 **DataFrame(2차원)** 의 개념과 동작 원리를 이해한다.
> - 데이터를 **만들고 → 불러오고 → 인덱스를 다루고 → 원하는 부분만 골라내는** 전 과정을, 각 함수·메소드의 **문법과 인수**까지 정확히 익힌다.
> - 이 구조가 이후 모든 데이터 분석(탐색·정제·집계)의 출발점임을 안다.
>
> **선행 지식**: 파이썬 기초(리스트, 딕셔너리), `import` 개념. NumPy는 몰라도 따라올 수 있음.

## 0. 들어가며 — 왜 Series와 DataFrame인가?

엑셀을 떠올려 보세요. 엑셀의 **한 개의 열**(예: 1월부터 6월까지의 매출액)이 판다스의 **Series**이고, 여러 열이 모인 **표 전체**(상품명·매출액·판매수량이 함께 있는 표)가 판다스의 **DataFrame**입니다.

| 엑셀 | 판다스 | 차원 |
|---|---|---|
| 한 개의 열 | **Series** | 1차원 |
| 표 전체(여러 열) | **DataFrame** | 2차원 |

**왜 굳이 새로운 구조를 배울까요?** 파이썬의 기본 리스트로도 숫자를 담을 수 있지만, "3월 매출만 꺼내기", "평균 구하기", "매출 높은 순 정렬" 같은 작업을 하려면 직접 반복문을 짜야 합니다. 판다스의 Series·DataFrame은 이런 작업을 **메소드 하나**로 끝낼 수 있게 설계된 "데이터 분석 전용 그릇"입니다.

```python
import pandas as pd   # 판다스를 pd라는 별명으로 불러옴 (관례)
```

> 💡 `as pd`는 전 세계 공통 관례입니다. 모든 예제에서 `pd`는 판다스를 가리킵니다.

## 1. Series — 1차원 데이터

### 1-1. 개념과 원리

**Series**는 **인덱스(index, 순서·이름표)** 와 **값(value)** 이 한 쌍씩 묶인 1차원 데이터입니다.

```
 인덱스    값
  1월  →  1500
  2월  →  2000
  3월  →  2500
```

**핵심 원리**: 리스트는 위치 번호(0, 1, 2…)로만 값을 찾지만, Series는 **각 값마다 고유한 인덱스(이름표)** 를 붙일 수 있습니다. 그래서 `매출액['3월']`처럼 **이름으로 바로 조회**가 가능하고, 인덱스를 기준으로 서로 다른 Series끼리 자동 정렬·계산도 됩니다.

### 1-2. 함수: `pd.Series()` — Series 만들기

**문법**
```python
pd.Series(data, index=None, dtype=None, name=None)
```

**인수 구성**

| 인수 | 의미 | 기본값 | 설명 |
|---|---|---|---|
| `data` | 담을 데이터 | (필수) | 리스트 / 딕셔너리 / 넘파이 배열 / 스칼라 |
| `index` | 인덱스(이름표) | `None` | 생략 시 0,1,2…가 자동 부여 |
| `dtype` | 자료형 | `None` | 보통 자동 추론(`int64`, `float64`, `object` 등) |
| `name` | Series 이름 | `None` | DataFrame의 열이 될 때 열 이름이 됨 |

### 1-3. 사용법 — Series를 만드는 4가지 방법

**① 리스트로 생성** (인덱스 생략 → 0부터 자동)
```python
매출액 = pd.Series([1500, 2000, 2500, 3000, 3500, 4000])
매출액
```
```
0    1500
1    2000
2    2500
3    3000
4    3500
5    4000
dtype: int64
```
> 왼쪽 `0~5`가 **자동 생성된 인덱스**, 오른쪽이 값입니다. `dtype: int64`는 "값이 64비트 정수"라는 뜻.

**② 리스트 + 인덱스 지정** (이름표를 직접 붙이기)
```python
매출액 = pd.Series([1500, 2000, 2500, 3000, 3500, 4000],
                 index=['1월', '2월', '3월', '4월', '5월', '6월'])
매출액
```
```
1월    1500
2월    2000
3월    2500
...
dtype: int64
```
이제 `매출액['3월']` → `2500` 처럼 **달 이름으로 조회**할 수 있습니다.

**③ 딕셔너리로 생성** (키=인덱스, 값=데이터)
```python
매출액 = pd.Series({'1월': 1500, '2월': 2000, '3월': 2500})
```
> 딕셔너리는 이미 "키:값" 구조라, **키가 그대로 인덱스**가 됩니다. 가장 직관적인 방법.

**④ 넘파이 배열로 생성** (대용량·고속 계산에 유리)
```python
import numpy as np
매출액 = pd.Series(np.array([1500, 2000, 2500, 3000]))
```

### 1-4. Series 통계 메소드

Series는 그 자체로 통계 메소드를 가집니다(값을 하나하나 더할 필요 없음).

| 메소드 | 의미 | 예시 |
|---|---|---|
| `.sum()` | 합계 | `매출액.sum()` → 16500 |
| `.mean()` | 평균 | `매출액.mean()` → 2750.0 |
| `.median()` | 중앙값 | `매출액.median()` → 2750.0 |
| `.min()` / `.max()` | 최소 / 최대 | `매출액.min()` → 1500 |

```python
print(매출액.sum())      # 16500
print(매출액.mean())     # 2750.0
print(매출액.min(), 매출액.max())   # 1500 4000
```

> 📊 **데이터 분석 관점**: 한 열(매출, 나이, 가격 등)의 전체 경향을 한 줄로 요약하는 것이 분석의 첫걸음입니다. 이 메소드들은 Part 2의 "기술 통계"로 그대로 이어집니다.

## 2. DataFrame — 2차원 데이터(표)

### 2-1. 개념과 원리

**DataFrame**은 **여러 개의 Series가 옆으로 나란히 모인 표**입니다. 세 가지 요소로 구성됩니다.

- **index(인덱스)** : 행(row)의 이름표 — 세로
- **columns(컬럼)** : 열(column)의 이름 — 가로(속성)
- **values(값)** : 실제 데이터

```
        상품명   매출액  판매수량   ← columns(열 이름)
   0    A제품    1500     100
   1    B제품    2000     150
   ↑
 index(행 이름표)
```

> **원리**: 각 열은 사실 하나의 Series입니다. `df['매출액']`을 꺼내면 그것은 다시 Series가 됩니다. 즉 **DataFrame = 이름표(index)를 공유하는 Series들의 묶음**입니다.

### 2-2. 함수: `pd.DataFrame()` — 표 만들기

**문법**
```python
pd.DataFrame(data, index=None, columns=None)
```

**① 딕셔너리로 생성** (키=열 이름, 값=열 데이터) — 가장 많이 씀
```python
데이터 = {
    '상품명': ['A제품', 'B제품', 'C제품', 'D제품'],
    '매출액': [1500, 2000, 2500, 3000],
    '판매수량': [100, 150, 200, 250]
}
df = pd.DataFrame(데이터)
df
```
> 딕셔너리의 **키가 열 제목**, 리스트가 **세로 한 줄(열)** 이 됩니다.

**② 리스트의 리스트로 생성** (안쪽 리스트 하나 = 한 행)
```python
df2 = pd.DataFrame([
    ['A제품', 1500, 100],
    ['B제품', 2000, 150],
], columns=['상품명', '매출액', '판매수량'])
```
> 이 방식은 행 단위로 데이터가 들어오므로 `columns=`로 열 이름을 따로 지정해야 합니다.

## 3. 인덱스·열 다루기 — `set_index` / `reset_index` / `rename` / `drop`

아래 예제는 주식 종목 데이터를 사용합니다.
```python
data = {
    '종목명': ['삼성전자', 'SK하이닉스', 'NAVER', '카카오', 'LG화학'],
    '종목코드': ['005930', '000660', '035420', '035720', '051910'],
    '현재가': [70000, 120000, 380000, 135000, 800000],
    '거래량': [1000000, 800000, 500000, 600000, 300000],
    '지역': ['서울', '서울', '성남', '성남', '서울']
}
df = pd.DataFrame(data)
```

> ⚠️ **공통 핵심: `inplace` 인수**
> 대부분의 변형 메소드에는 `inplace`라는 인수가 있습니다.
> - `inplace=False`(기본): 변형된 **새 결과를 돌려주고**, 원본은 그대로 둠 → `df2 = df.메소드(...)`처럼 받아야 함
> - `inplace=True`: **원본 df를 직접 바꿈**(돌려주는 값 없음)
> 초보 단계에서 가장 헷갈리는 부분이니 꼭 기억하세요.

### 3-1. `set_index()` — 특정 열을 인덱스(행 이름표)로 지정

**개념**: 행을 구분하는 식별자를 0,1,2… 대신 의미 있는 열(예: 종목코드)로 바꿉니다.

**문법 / 인수**
```python
df.set_index(keys, drop=True, inplace=False)
```

| 인수 | 의미 | 기본값 |
|---|---|---|
| `keys` | 인덱스로 쓸 열 이름 | (필수) |
| `drop` | 인덱스로 보낸 열을 표에서 **삭제**할지 | `True` |
| `inplace` | 원본에 바로 적용 | `False` |

**사용법**
```python
# 종목코드를 인덱스로, 원래 열은 남겨둠
df.set_index('종목코드', drop=False)

# 원본 df에 바로 반영 (종목코드 열은 사라지고 인덱스가 됨)
df.set_index('종목코드', drop=True, inplace=True)
```

### 3-2. `reset_index()` — 인덱스를 원래대로(0,1,2…) 되돌리기

**개념**: `set_index`의 반대. 인덱스로 보냈던 값을 **다시 일반 열로** 꺼내거나, 정수 인덱스로 초기화합니다.

```python
df.reset_index(drop=False, inplace=False)
```

| 인수 | 의미 | 기본값 |
|---|---|---|
| `drop` | 기존 인덱스를 **열로 살리지 않고 버릴지** | `False` |
| `inplace` | 원본에 바로 적용 | `False` |

```python
df.reset_index(inplace=True)            # 인덱스를 열로 되살림
df.reset_index(drop=True, inplace=True) # 인덱스를 그냥 버리고 0,1,2…로
```

### 3-3. `rename()` — 행·열 이름 바꾸기

**개념**: 열 제목이나 행 이름표를 **딕셔너리(`{옛이름: 새이름}`)** 로 바꿉니다.

```python
df.rename(columns={'옛열': '새열'}, index={'옛행': '새행'}, inplace=False)
```

| 인수 | 의미 |
|---|---|
| `columns={...}` | 열 이름 변경 |
| `index={...}` | 행 이름(인덱스) 변경 |
| `inplace` | 원본에 바로 적용 |

```python
df.rename(columns={'종목명': '회사명', '현재가': '가격'}, inplace=True)
df.rename(index={'005930': '삼성전자'}, inplace=True)
```
> 💡 바꾸고 싶은 것만 딕셔너리에 적으면 됩니다. 나머지는 그대로 유지됩니다.

### 3-4. `drop()` — 행 또는 열 삭제

**개념**: 필요 없는 행이나 열을 제거합니다. **`axis`로 방향을 지정**하는 것이 핵심입니다.

```python
df.drop(labels, axis=0, inplace=False)
```

| 인수 | 의미 | 값 |
|---|---|---|
| `labels` | 삭제할 이름(들) | 문자열 또는 리스트 |
| `axis` | 삭제 방향 | `0`=행(가로줄), `1`=열(세로줄) |
| `inplace` | 원본에 바로 적용 | `False` |

```python
df2 = df.drop('회사명', axis=1)                      # '회사명' 열 삭제
df3 = df.drop(labels=['삼성전자','SK하이닉스'], axis=0) # 두 행 삭제
```
> ⚠️ **`axis` 외우기**: `axis=0`은 위→아래(행), `axis=1`은 좌→우(열). 헷갈리면 "0은 행, 1은 열"로 암기하세요.

## 4. 데이터 불러오기 — `pd.read_csv()`

실무에서는 데이터를 직접 입력하지 않고 **CSV 파일에서 불러옵니다.** 이것이 분석의 진짜 시작점입니다.

**문법**
```python
pd.read_csv(filepath, encoding=None, index_col=None, header=0, usecols=None, nrows=None)
```

**자주 쓰는 인수**

| 인수 | 의미 | 예시 |
|---|---|---|
| `filepath` | 파일 경로/이름 | `"Data01.csv"` |
| `encoding` | 한글 깨짐 방지 인코딩 | `"cp949"`, `"euc-kr"`, `"utf-8"` |
| `index_col` | 인덱스로 쓸 열 | `index_col=0` 또는 `"종목코드"` |
| `header` | 열 이름이 있는 행 번호 | 기본 `0`(첫 줄). 없으면 `header=None` |
| `usecols` | 특정 열만 읽기 | `usecols=['상품명','매출액']` |
| `nrows` | 위에서 N행만 읽기 | `nrows=100` |

```python
# 한글이 깨질 때는 encoding 지정
df = pd.read_csv("Data01.csv", encoding="cp949")

# 필요한 열만, 특정 열을 인덱스로
df = pd.read_csv("Data01.csv", usecols=['종목명','현재가'], index_col='종목명')
```

> 💡 **한글 인코딩 팁**: 윈도우에서 만든 파일은 `cp949`(=euc-kr), 그 외/웹은 `utf-8`이 많습니다. `UnicodeDecodeError`가 나면 인코딩을 바꿔 보세요.

저장은 반대로 `df.to_csv("결과.csv", index=False)`, `df.to_excel("결과.xlsx")`를 씁니다. (자세히는 Part 4)

## 5. 데이터 선택 — 원하는 부분만 꺼내기

### 5-1. 전체 훑어보기 — `head` / `tail` / `sample`

| 메소드 | 의미 |
|---|---|
| `df.head(n)` | 위에서 n행 (기본 5) |
| `df.tail(n)` | 아래에서 n행 |
| `df.sample(n)` | 무작위 n행 |

```python
df.head()      # 상위 5행
df.tail(10)    # 하위 10행
df.sample(3)   # 랜덤 3행
```
> 📊 데이터를 불러온 직후 `head()`로 "어떤 모양인지" 눈으로 확인하는 습관이 중요합니다.

### 5-2. 열 선택

```python
df['종목명']               # 한 열 → Series로 반환
df[['종목명', '현재가']]    # 여러 열 → DataFrame으로 반환 (대괄호 두 겹!)
df[['종목명','현재가']].head()   # 선택 후 상위 5개
```
> ⚠️ 열 하나는 `df['열']`, 여러 열은 **리스트로 감싸서** `df[['열1','열2']]`. 대괄호 개수가 다릅니다.

### 5-3. `iloc[]` — **숫자 위치**로 선택

**개념**: integer location. 행·열을 **0부터 시작하는 정수 위치**로 선택합니다. 파이썬 슬라이싱(`start:end:step`)과 똑같이 동작하며, **끝 위치는 포함하지 않습니다.**

**문법**: `df.iloc[행위치, 열위치]`

```python
df.iloc[0]        # 첫 번째 행
df.iloc[2]        # 세 번째 행
df.iloc[0:5]      # 0~4행 (5는 제외) — df.iloc[:5] 와 동일
df.iloc[:10:2]    # 0~9행을 2칸씩 건너뛰며
df.iloc[5:]       # 5행부터 끝까지
df.iloc[2:-2]     # 3번째 행 ~ 끝에서 2번째 행
```
> 💡 `-2`처럼 음수는 "뒤에서부터" 셉니다. `-1`이 마지막.

### 5-4. `loc[]` — **이름(라벨)** 으로 선택

**개념**: location. 행·열을 **인덱스 이름 / 열 이름**으로 선택합니다. `iloc`과 달리 **끝 라벨을 포함합니다.**

**문법**: `df.loc[행이름, 열이름]`

```python
df2 = df.set_index('종목명', drop=True)   # 종목명을 인덱스로

df2.loc['삼성전자']                       # 특정 행
df2.loc[['삼성전자', 'NAVER']]            # 떨어진 여러 행
df2.loc['삼성전자':'LG화학']              # 연속 행 (끝 포함!)
df2.loc[:, '지역']                        # 모든 행의 '지역' 열
df2.loc[:, ['현재가','지역']]             # 모든 행의 여러 열
df2.loc[:, '현재가':'지역']               # 현재가~지역 열 범위
df2.loc['삼성전자':'LG화학', '현재가':'지역']  # 행·열 동시
```

### 5-5. `iloc` vs `loc` 비교 (가장 중요!)

| 구분 | `iloc[]` | `loc[]` |
|---|---|---|
| 기준 | **숫자 위치**(0,1,2…) | **이름(라벨)** |
| 끝 포함 | ❌ `0:5` → 0~4 | ✅ `'A':'C'` → A~C |
| 예 | `df.iloc[0, 1]` | `df.loc['삼성전자', '지역']` |
| 언제 | 위치를 알 때, 순번 처리 | 의미 있는 이름으로 고를 때 |

> ⚠️ **초보 최대 실수**: `loc`은 끝을 포함, `iloc`은 끝을 제외합니다. `df.loc['A':'C']`는 A,B,C 셋, `df.iloc[0:3]`은 0,1,2 셋(3 제외).

## 6. 데이터 분석 프로세스에서의 위치

이 파트는 분석의 **0단계: 데이터 준비**에 해당합니다.

```
[Part 1] 불러오기·구조 → [Part 2] 탐색 → [Part 3~6] 정제 → [Part 7~9] 결합·요약
   ▲ 지금 여기
```

실무 흐름 예시:
```python
df = pd.read_csv("주식데이터.csv", encoding="cp949")  # ① 불러오기
df.head()                                            # ② 모양 확인
df = df.set_index('종목코드')                          # ③ 식별자 정리
df = df.drop('불필요열', axis=1)                       # ④ 필요 없는 열 제거
관심 = df.loc[:, ['종목명','현재가']]                   # ⑤ 분석할 부분만 선택
```
이렇게 "불러오고 → 보고 → 정돈하고 → 골라내는" 한 사이클이 모든 분석의 출발점입니다.

## 7. 자주 하는 실수 체크리스트

- [ ] `import pandas as pd`를 빼먹지 않았는가
- [ ] 여러 열 선택 시 대괄호 두 겹 `df[['a','b']]`을 썼는가
- [ ] `inplace=True`를 안 썼는데 원본이 안 바뀐다고 당황하지 않았는가 (결과를 변수로 받아야 함)
- [ ] `drop`에서 행은 `axis=0`, 열은 `axis=1`로 맞췄는가
- [ ] `iloc`(끝 제외)과 `loc`(끝 포함)을 혼동하지 않았는가
- [ ] 한글 CSV에서 `encoding`을 지정했는가

## 8. 핵심 요약

1. **Series**는 인덱스+값의 1차원, **DataFrame**은 여러 Series가 모인 2차원 표.
2. 생성: `pd.Series()`, `pd.DataFrame()` — 리스트·딕셔너리·배열로 만든다.
3. 인덱스 관리: `set_index`(열→인덱스), `reset_index`(되돌리기), `rename`(이름 변경), `drop`(삭제, `axis` 주의).
4. 불러오기: `pd.read_csv()` — `encoding`, `index_col`, `usecols`가 단골 인수.
5. 선택: 열은 `df['열']`/`df[['열들']]`, 행·열은 `iloc[]`(숫자·끝제외) / `loc[]`(이름·끝포함).
6. 변형 메소드의 `inplace` 동작을 항상 의식한다.
