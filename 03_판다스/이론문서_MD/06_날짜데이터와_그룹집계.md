df = pd.read_csv('03_Delivery.csv', encoding='cp949')

## 0. 들어가며 — 날짜는 분석의 핵심 축

판매·주가·트래픽 등 거의 모든 비즈니스 데이터는 **시간의 흐름**을 가집니다. "월별 매출 추세", "요일별 주문량", "계절성" 같은 분석은 모두 날짜에서 출발합니다.

문제는, CSV에서 날짜는 보통 **그냥 문자열**(`'20230101'`)로 들어온다는 점입니다. 문자열 상태로는 "월만 뽑기", "기간 계산하기"가 안 됩니다. 그래서 두 단계가 필요합니다.

1. **날짜형으로 변환** (`to_datetime`) → 2. **연·월·요일 추출**(`.dt`) → 3. **그 기준으로 집계**(`groupby`)

> 📊 **분석 프로세스상 위치**: `[Part 5] 정제 → [Part 6] 날짜 가공·그룹 집계(지금) → [Part 7~9] 결합·요약`. 이 파트에서 처음으로 **"기준별로 묶어 요약하는"** 진짜 분석을 합니다.

## 1. `to_datetime()` — 문자열을 날짜로 변환

**개념**: `'20230101'` 같은 문자열/숫자를 판다스가 이해하는 **날짜형(datetime64)** 으로 바꿉니다.

**원리**: 날짜형이 되어야 비로소 `.dt`로 연·월·요일을 뽑고, 날짜끼리 빼서 기간을 구할 수 있습니다. 변환 전에는 그냥 글자라 불가능합니다.

**문법 / 인수**
```python
pd.to_datetime(arg, format=None)
```

| 인수 | 의미 | 예 |
|---|---|---|
| `arg` | 변환할 열/값 | `df['주문일']` |
| `format` | 입력 날짜의 형식(지정 시 빠르고 안전) | `'%Y%m%d'` = YYYYMMDD |

`format` 기호: `%Y`(4자리 연), `%m`(월), `%d`(일), `%H`(시), `%M`(분).

**사용법**
```python
df['주문일'] = pd.to_datetime(df['주문일'], format='%Y%m%d')
df['주문일'].dtype       # datetime64[ns]  ← 날짜형으로 변환됨
```

> 💡 변환에 성공하면 `dtype`이 `object`(문자)에서 **`datetime64[ns]`** 로 바뀝니다. 이 확인이 중요합니다.

---

## 2. `.dt` 접근자 — 연·월·주차·요일 추출

**개념**: 날짜형 열에 `.dt`를 붙이면 날짜의 **구성 요소**를 꺼낼 수 있습니다. 새 열로 추가해 분석 기준을 만듭니다.

| 코드 | 추출 | 결과 예 |
|---|---|---|
| `.dt.year` | 연도 | 2023 |
| `.dt.month` | 월(1~12) | 1 |
| `.dt.day` | 일 | 7 |
| `.dt.isocalendar().week` | ISO 주차 | 1 |
| `.dt.day_name()` | 요일(영문) | `'Monday'` |

```python
df['연도'] = df['주문일'].dt.year
df['월']   = df['주문일'].dt.month
df['주차'] = df['주문일'].dt.isocalendar().week
df['요일'] = df['주문일'].dt.day_name()
```

> ⚠️ `.dt.year`는 **속성**(괄호 없음)이지만 `.dt.day_name()`은 **메소드**(괄호 있음)입니다. 헷갈리기 쉬우니 주의하세요.

> 📊 이렇게 만든 '연도'·'월'·'요일' 열이 다음 단계 `groupby`의 **집계 기준**이 됩니다.

---

## 3. `groupby()` — 기준별로 묶어 집계

**개념**: 데이터를 **특정 기준(열)으로 그룹화**한 뒤, 그룹마다 합계·평균 등을 계산합니다. 엑셀의 "부분합"이나 피벗의 핵심 동작입니다.

**원리 — 분리·적용·결합(split-apply-combine)**: ① 기준 열의 값에 따라 행들을 그룹으로 **나누고(split)**, ② 각 그룹에 집계 함수를 **적용(apply)**, ③ 결과를 하나로 **합칩니다(combine)**.

**문법**
```python
df.groupby('기준열')['집계할열'].집계함수()
```

**한 기준, 한 열 집계**
```python
df.groupby('연도')['수량'].sum()      # 연도별 주문 수량 합계
```
```
연도
2017     2044
2018    31538
2019    21445
Name: 수량, dtype: int64
```

**여러 기준** — 리스트로(다중 인덱스 결과)
```python
df.groupby(['연도', '월'])['수량'].sum()    # 연도×월별 수량 합계
```

> 💡 `groupby` 결과는 **기준 열이 인덱스**가 됩니다. 표로 다시 다루려면 `reset_index()`로 일반 열로 되돌립니다(Part 1).

---

## 4. `agg()` — 여러 통계를 한 번에

**개념**: `groupby` 뒤에 붙여 **여러 집계 함수를 동시에**, 또는 **열마다 다른 집계**를 적용합니다.

**① 한 열에 여러 함수** — 리스트
```python
df.groupby('연도')['수량'].agg(['sum', 'mean'])
```
```
        sum  mean
연도
2017   2044  1.25
2018  31538  1.14
2019  21445  1.22
```

**② 열마다 다른 함수** — 딕셔너리 `{열: 함수}`
```python
df.groupby(['연도', '월']).agg({'상품구매금액': 'sum', '수량': 'mean'})
```
> 상품구매금액은 합계, 수량은 평균 — 열마다 다른 통계를 한 번에 냅니다.

| 방식 | 문법 | 의미 |
|---|---|---|
| 여러 함수 | `.agg(['sum','mean'])` | 한 열에 여러 통계 |
| 열별 함수 | `.agg({'A':'sum','B':'mean'})` | 열마다 다른 통계 |

> 📊 "요일별 매출 합계·평균·건수"처럼 한 번에 여러 각도로 요약할 때 `agg`가 필수입니다.
> ```python
> df.groupby('요일')['상품구매금액'].agg(['sum', 'mean', 'count'])
> ```

## 5. `replace()` — 값 치환

**개념**: 특정 값을 다른 값으로 **바꿉니다**. 오류 값 보정이나 범주 재분류에 씁니다.

**문법 / 인수**
```python
df.replace(to_replace, value, inplace=False)
```

**① 단일 값 치환** — 오류 값 보정
```python
df.replace(to_replace=-9999, value=0, inplace=True)    # 오류코드 -9999 → 0
```

**② 딕셔너리로 여러 값 치환** — 범주 재분류
```python
df['주중/주말'] = df['요일'].replace({
    'Monday':'주중','Tuesday':'주중','Wednesday':'주중','Thursday':'주중','Friday':'주중',
    'Saturday':'주말','Sunday':'주말'
})
df['주중/주말'].value_counts()
```
```
주중    42406
주말     4343
```
> 이제 '주중/주말'을 기준으로 `groupby`하면 주중·주말 매출을 비교할 수 있습니다.
> ```python
> df.groupby('주중/주말')['상품구매금액'].mean()
> ```

> 📊 `replace`로 만든 새 범주(주중/주말, 등급 묶음 등)는 분석의 새로운 **집계 축**이 됩니다.

## 6. `apply()` — 사용자 정의 함수 적용

**개념**: 판다스 기본 함수로 부족할 때, **내가 만든 함수(`def`)** 를 열/행의 모든 값에 적용합니다.

**원리**: `apply(함수)`는 그 함수를 각 값마다 **하나씩 호출**해 결과를 모읍니다. "각 값에 같은 처리를 반복"할 때 반복문 없이 한 줄로 끝냅니다.

**문법**
```python
df['열'].apply(함수)        # 함수에 괄호 없이 이름만 전달
```

**사용법**
```python
def 더하기_10(x):
    return x + 10

df['A_변경'] = df['A'].apply(더하기_10)    # A의 모든 값에 +10
```
간단한 함수는 람다로:
```python
df['A_변경'] = df['A'].apply(lambda x: x + 10)
```

> ⚠️ `apply(더하기_10)` 처럼 **함수 이름만** 넘깁니다. `apply(더하기_10())` 처럼 괄호를 붙이면 안 됩니다(미리 실행돼 버림).

## 7. 실전 — 배송기간 계산 (split + apply + 날짜 뺄셈)

배운 것을 모아 "평균 배송기간"을 구합니다. 배송시작일/완료일이 `'2019-01-07 오전 8:56'`처럼 **날짜+시간 문자열**입니다.

**① 문자열 분리 — `split()`**: 공백 기준으로 날짜 부분만.
```python
text = "주식,채권,부동산"
text.split(',')         # ['주식', '채권', '부동산']  (구분자로 쪼개 리스트 반환)

"2019-01-07 오전 8:56".split(" ")[0]    # '2019-01-07'  (앞부분만)
```

**② 함수로 만들어 `apply`로 전 행에 적용 → 날짜 변환**
```python
def 분리하기(행):
    return 행.split(" ")[0]

df['시작(date)'] = pd.to_datetime(df['배송시작일'].apply(분리하기))
df['완료(date)'] = pd.to_datetime(df['배송완료일'].apply(분리하기))
```

**③ 날짜 뺄셈 → 기간(timedelta)**
```python
df['배송기간'] = df['완료(date)'] - df['시작(date)']    # 결과는 '4 days' 형태
df['배송기간'].describe()                              # 평균 약 4.19일
```

**④ 일수만 숫자로 뽑아 조건 필터 → 저장**
```python
def 일수만(행):
    return int(str(행).split(" ")[0])      # '4 days' → 4

df['배송기간(일)'] = df['배송기간'].apply(일수만)
지연 = df[df['배송기간(일)'] >= 7]            # 7일 이상 지연 건 (1,611건)
지연.to_csv('배송지연건.csv', index=False)
```

> 📊 날짜형끼리 빼면 **기간(timedelta)** 이 나옵니다. 이것이 "배송 소요일", "가입 후 경과일" 같은 핵심 지표의 출발점입니다.

## 8. 데이터 분석 프로세스에서의 활용 (날짜 분석 한 사이클)

```python
# ① 날짜 변환
df['주문일'] = pd.to_datetime(df['주문일'], format='%Y%m%d')

# ② 분석 축 만들기
df['연도'] = df['주문일'].dt.year
df['요일'] = df['주문일'].dt.day_name()
주말맵 = {'Monday':'주중','Tuesday':'주중','Wednesday':'주중','Thursday':'주중',
        'Friday':'주중','Saturday':'주말','Sunday':'주말'}
df['주중/주말'] = df['요일'].replace(주말맵)

# ③ 기준별 집계
df.groupby('연도')['상품구매금액'].agg(['sum', 'mean'])     # 연도 추세
df.groupby('요일')['수량'].sum()                          # 요일 패턴
```

**변환 → 축 생성 → 집계** 의 흐름으로 "언제 많이 팔리는가", "추세는 어떤가"에 답합니다. 이 그룹 집계가 다음 파트(피벗테이블)로 확장됩니다.

## 9. 자주 하는 실수 체크리스트

- [ ] `to_datetime` 후 `dtype`이 `datetime64`로 바뀐 것을 확인했는가
- [ ] `.dt.year`(속성, 괄호X) / `.dt.day_name()`(메소드, 괄호O) 구분했는가
- [ ] `groupby` 결과의 기준 열이 인덱스가 된 점을 알고, 필요 시 `reset_index` 했는가
- [ ] `agg`에서 여러 함수는 리스트, 열별 함수는 딕셔너리로 구분했는가
- [ ] `apply`에 함수 **이름만**(괄호 없이) 넘겼는가
- [ ] 날짜 뺄셈 결과(timedelta)에서 일수를 쓸 때 숫자로 변환했는가

## 10. 핵심 요약

1. `to_datetime(열, format=...)` 로 문자열을 **날짜형**으로 바꿔야 날짜 분석이 시작된다.
2. `.dt.year`/`.dt.month`/`.dt.day_name()` 으로 분석 축(연·월·요일)을 만든다.
3. `groupby('기준')['열'].집계()` 는 **분리-적용-결합**으로 기준별 요약을 만든다.
4. `agg`: 여러 함수는 **리스트**, 열별 함수는 **딕셔너리**.
5. `replace`(값 치환), `apply`(사용자 함수), `split`(문자 분리)로 원하는 형태로 가공한다.
6. 날짜끼리 빼면 **기간(timedelta)** — 소요일 같은 지표를 만든다.
