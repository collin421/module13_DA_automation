## 0. 들어가며 — 흩어진 도구를 하나의 흐름으로

지금까지 배운 것은 개별 도구였습니다. 이 파트에서는 그 도구들을 **하나의 실무 과제**로 꿰어 봅니다.

> 🎯 **과제 시나리오**: "VIP 회원 중 **모바일 알람을 신청한 고객**에게 사은품을 보내려 한다. 대상 고객 명단을 뽑아 **엑셀 파일로** 마케팅팀에 전달하라."

```

```

마지막 **"파일로 저장"** 이 이 파트의 새 주제입니다. 분석은 결과를 다른 사람이 쓸 수 있는 형태로 **내보내야** 비로소 끝납니다.

## 3. 데이터 저장 — `to_csv()` / `to_excel()`

분석 결과(DataFrame)를 컴퓨터의 **파일로 내보내는** 메소드입니다. 메모리 안의 표를 디스크의 csv·xlsx 파일로 "저장"합니다.

### 3-1. `to_excel()` — 엑셀 파일로 저장

**개념**: DataFrame을 `.xlsx`(엑셀) 파일로 저장합니다.

**원리**: 내부적으로 엑셀 작성 엔진(`openpyxl`)을 사용합니다. 설치되어 있지 않으면 `pip install openpyxl`이 필요합니다.

**문법 / 인수**
```python
df.to_excel(excel_writer, sheet_name='Sheet1', index=True)
```

| 인수 | 의미 | 기본값 |
|---|---|---|
| `excel_writer` | 저장할 파일 이름/경로 | (필수) |
| `sheet_name` | 시트 이름 | `'Sheet1'` |
| `index` | 행 인덱스를 함께 저장할지 | `True` |

**사용법**
```python
df_vip.to_excel('vip_alert_member.xlsx')      # 현재 폴더에 엑셀 생성
```
> 실행 후 폴더에 `vip_alert_member.xlsx`가 생기고, 더블클릭하면 엑셀에서 70명 명단이 열립니다.

### 3-2. `to_csv()` — CSV 파일로 저장

**개념**: DataFrame을 `.csv`(쉼표로 구분된 텍스트) 파일로 저장합니다. 가장 가볍고 호환성이 높은 형식.

**문법 / 인수**
```python
df.to_csv(path, index=True, encoding=None)
```

| 인수 | 의미 | 기본값 |
|---|---|---|
| `path` | 저장할 파일 이름/경로 | (필수) |
| `index` | 행 인덱스를 함께 저장할지 | `True` |
| `encoding` | 인코딩 | `'utf-8'` |

```python
df_vip.to_csv('vip_명단.csv', index=False, encoding='utf-8-sig')
```

> ⚠️ **꼭 기억할 두 가지**
> 1. **`index=False`**: 기본값 `True`면 의미 없는 인덱스 열(0,1,2…)이 파일에 같이 저장됩니다. 보통 `index=False`로 끕니다.
> 2. **한글 깨짐**: CSV를 엑셀로 열 때 한글이 깨지면 `encoding='utf-8-sig'`(또는 `'cp949'`)로 저장하세요.

| | `to_csv` | `to_excel` |
|---|---|---|
| 형식 | 텍스트(.csv) | 엑셀(.xlsx) |
| 용량/속도 | 가볍고 빠름 | 무겁지만 서식·시트 지원 |
| 추가 설치 | 불필요 | `openpyxl` 필요 |
| 단골 인수 | `index=False`, `encoding` | `index`, `sheet_name` |

> 📊 분석 결과를 **마케팅팀에 전달**하면 엑셀(`to_excel`), **다른 코드/시스템 입력**으로 쓰면 CSV(`to_csv`)가 일반적입니다.

## 4. 실전 응용 — 정렬·입력과 결합

### 4-1. 정렬 후 저장 (Top-N 추출)

"VIP 중 총구매금액이 **낮은** 상위 10명"을 뽑는 과제. 필터 → 정렬 → 상위 → 저장.

```python
cond = df['VIP회원'] == 'VIP'
df_sort = df[cond].sort_values(by='총구매금액')   # 낮은 금액부터 오름차순
df_sort.head(10)                                 # 하위 10명
df_sort.head(10).to_csv('vip_저구매_top10.csv', index=False)
```
```
     VIP회원    총구매금액
853    VIP  2497794
445    VIP  2741376
1272   VIP  2939392
...
```

### 4-2. 입력값으로 조건이 바뀌는 자동화

`input()`으로 받은 값을 조건에 넣고, **f-string**으로 파일 이름까지 동적으로 만듭니다.

**지역별 VIP 명단 자동 저장**
```python
지역 = input('지역을 입력하세요 : ')      # 예: 수지구

cond1 = df['VIP회원'] == 'VIP'
cond2 = df['Address'] == 지역
df.loc[cond1 & cond2].to_csv(f'{지역}_vip.csv', index=False)   # → '수지구_vip.csv'
```

**연령 구간으로 회원 추출** (`between` 활용)
```python
연령_최소값 = int(input('최소 연령 : '))     # input은 문자열이라 int로 변환
연령_최대값 = int(input('최대 연령 : '))

cond = df['Age'].between(연령_최소값, 연령_최대값)
df.loc[cond].to_csv('연령별_member.csv', index=False)
```

> ⚠️ `input()`은 **항상 문자열**을 돌려줍니다. 숫자 비교에 쓰려면 `int()`/`float()`로 변환해야 합니다(파이썬 기초 복습).

> 💡 이렇게 만들면 코드를 고치지 않고 **입력만 바꿔** 지역별·연령별 명단을 반복 생산할 수 있습니다. 이것이 "한 번 짜서 반복하는" 자동화의 핵심입니다.

## 5. 데이터 분석 프로세스에서의 활용 (전체 파이프라인)

이 파트의 미니 프로젝트를 한눈에 정리하면:

```python
import pandas as pd

# ① 불러오기
df = pd.read_csv('02_VIP_member_Data.csv')

# ② 구조 파악
df.info()
df['VIP회원'].value_counts()

# ③ 조건 필터
조건1 = df['VIP회원'] == 'VIP'
조건2 = df['모바일알람여부'] == '수신'
대상 = df.loc[조건1 & 조건2]

# ④ 정렬(선택) — 필요 시 우선순위 부여
대상 = 대상.sort_values(by='총구매금액', ascending=False)

# ⑤ 저장 — 결과물 산출
대상.to_excel('vip_alert_member.xlsx', index=False)
```

**불러오기 → 파악 → 필터 → 정렬 → 저장** — 이 다섯 단계가 가장 기본적인 분석 1사이클이며, 앞으로 배울 전처리·집계도 이 골격 위에 얹힙니다.

## 6. 자주 하는 실수 체크리스트

- [ ] 필터 조건의 값을 `value_counts()`로 **먼저 확인**했는가(`'수신'`인지 `'신청'`인지)
- [ ] 저장 시 `index=False`로 불필요한 인덱스 열을 껐는가
- [ ] 한글이 깨질 때 `encoding='utf-8-sig'` 또는 `'cp949'`를 줬는가
- [ ] `to_excel` 사용 시 `openpyxl`이 설치되어 있는가
- [ ] `input()` 결과를 숫자로 쓸 때 `int()`/`float()`로 변환했는가
- [ ] 파일이 이미 열려 있는 상태로 같은 이름에 저장하려다 권한 오류가 나지 않았는가

## 7. 핵심 요약

1. 실무 분석은 **불러오기 → 구조 파악 → 필터 → 정렬 → 저장**의 한 사이클이다.
2. 저장: `to_csv()`(가볍고 호환성↑), `to_excel()`(서식·시트, `openpyxl` 필요).
3. 저장 시 거의 항상 **`index=False`**, 한글은 **`encoding='utf-8-sig'`/`'cp949'`**.
4. `input()` + f-string으로 **조건과 파일명이 바뀌는 자동화** 코드를 만든다(`input`은 문자열 → 형변환 주의).
5. 조건은 변수로 조립하면 길어져도 읽기 쉽다.
