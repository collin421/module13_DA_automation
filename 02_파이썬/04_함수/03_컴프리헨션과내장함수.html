컴프리헨션과 내장 함수

데이터 가공을 가장 간결하게. 컴프리헨션은 for+append를 한 줄로 압축한 표현(Part 13의 [s["이름"] for s in ...]!). 그리고 enumerate·zip·sum·sorted 같은 내장 함수로 흔한 작업을 한 줄에.

🟠 함수 · 14/18 컴프리헨션 · 내장 함수 예상 35분
14-1

리스트 컴프리헨션

[표현식 for 변수 in 묶음] — "묶음의 각 값을 가공해 새 리스트로". for+append 세 줄과 완전히 같은 동작을 한 줄로, "새 리스트를 만든다"는 의도가 한눈에.

📌 참고  컴프리헨션과 for+append는 결과가 같음 — 익숙해지면 줄여 씀. 복잡한 로직은 일반 for가 읽기 좋음. "딕셔너리들의 리스트에서 한 속성 뽑기"([d["가격"] for d in 데이터])가 데이터 분석 단골.
3줄 요약
  1. 컴프리헨션은 for+append를 한 줄로 압축.
  2. [표현식 for 변수 in 묶음] — 각 값을 가공해 새 리스트.
  3. "한 속성만 뽑기"가 데이터 분석의 단골 패턴.
인터랙티브 · for+append → 컴프리헨션

변환을 골라, 같은 일을 하는 for문과 컴프리헨션을 나란히 비교(결과 동일).

14-2

조건이 있는 컴프리헨션

끝에 if 조건을 붙이면 조건 맞는 값만 담음 — for+if+append(필터)를 한 줄로. 변환과 필터를 동시에 할 수도 있음.

📌 참고  [표현식 for x in 묶음 if 조건]의 if는 "담을지 말지"를 거름. (표현식 자리의 if-else는 "값을 둘 중 하나로 바꾸기"라 위치가 다름 — 헷갈리면 일반 for로.)
3줄 요약
  1. [표현식 for x in 묶음 if 조건]으로 필터.
  2. for+if+append를 한 줄로 압축.
  3. 변환과 필터를 동시에 할 수 있음.
인터랙티브 · 조건으로 거르기

조건을 바꿔, 통과하는 값만 새 리스트에 담기는 걸 봄.

14-3

딕셔너리 컴프리헨션

{키: 값 for 변수 in 묶음} — :로 키·값을 구분하는 것만 다름. 기존 딕셔너리 일괄 변형이나 두 리스트 매핑에 유용함.

📌 참고  .items()(Part 7) + 언패킹(Part 6)이 자연스럽게 쓰임. "딕셔너리 값 일괄 변환"(단위·세율 적용)이나 "두 리스트를 zip으로 묶어 딕셔너리로"에 유용함.
3줄 요약
  1. {키: 값 for 변수 in 묶음}으로 딕셔너리 생성.
  2. .items() + 언패킹으로 기존 딕셔너리 변형.
  3. 두 리스트를 zip으로 묶어 딕셔너리로도.
인터랙티브 · 가격표 일괄 변형

변형을 골라, 딕셔너리의 모든 값이 한 번에 바뀌는 걸 봄.

14-4

enumerate와 zip

enumerate는 번호(인덱스)와 값을 함께, zip은 여러 묶음을 같은 위치끼리 짝지어 내어 줌. 둘 다 for와 쓰면 흔한 작업이 간결해짐(이름은 지퍼 zip에서).

📌 참고  "번호 필요하면 enumerate, 두 묶음 나란히면 zip". 둘이 내어 주는 짝은 튜플이고 for 번호, 값 in ...은 언패킹(Part 6). range(len(...))보다 enumerate가 파이썬다움.
3줄 요약
  1. enumerate는 번호와 값을 함께(0부터, 시작값 지정 가능).
  2. zip은 여러 묶음을 같은 위치끼리 짝지어 줌.
  3. 둘 다 튜플을 언패킹해 for ... in ...으로 씀.
인터랙티브 · 번호 붙이기 / 짝짓기

enumerate(번호+값)와 zip(두 리스트 짝)을 골라 결과를 봄.

14-5

집계 내장 함수

컴프리헨션으로 한 속성을 뽑아 sum·max·sorted·any·all에 넣는 것이 데이터 분석의 핵심 골격. Part 8의 모든 작업이 한 줄씩으로.

📌 참고  sum(s["재고"] for s in 목록)처럼 함수 괄호 안에 컴프리헨션을 바로 넣을 수 있음(대괄호 생략). any/all로 "하나라도/모두"를 한 줄로 검증함.
3줄 요약
  1. 컴프리헨션으로 뽑고 sum·max·len으로 요약.
  2. sorted·any·all도 유용함.
  3. Part 8의 모든 작업이 한 줄씩으로 간결해짐.
인터랙티브 · 뽑고 → 요약

집계를 골라, 컴프리헨션으로 뽑은 값을 내장 함수로 요약하는 걸 봄.
