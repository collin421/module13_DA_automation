함수 기초

한 묶음의 일에 이름을 붙여 재사용하는 도구. 반복되는 처리를 한 번 정의(def)해 두고 여러 번 부름. Part 8~11에서 손으로 짠 처리를 함수로 묶으면 코드가 짧고·명확하고·재사용 가능해짐 — 진짜 프로그램다워지는 단계.

12-1

함수 — 일에 이름 붙이기

def 이름():로 코드를 묶어 정의하고, 이름()으로 호출함. 정의는 실행이 아님 — 호출할 때 비로소 실행되고, 부를 때마다 재실행됨(재사용). 레시피를 적어 두는 것과 실제 요리의 차이.

📌 참고  우리가 써온 print()·len()·sum()도 함수. 함수의 가치는 재사용과 이름 — 같은 코드를 복사하는 대신 한 번 정의해 부르고, 고칠 때도 한 곳만 고침. 잘 지은 이름은 의도를 설명함.
3줄 요약
  1. 함수는 코드를 하나의 이름으로 묶은 것, def로 정의.
  2. 정의는 실행이 아님 — 호출(이름())할 때 실행.
  3. 한 번 정의해 여러 번 부르는 재사용이 핵심.
인터랙티브 · 정의 vs 호출

"호출"을 누를 때마다 함수 몸체가 실행되는 걸 봄(정의는 실행되지 않음).

12-2

매개변수와 인자

괄호 안 매개변수로 바깥 값을 받아, 같은 함수를 다른 값으로 재사용함. 호출 시 넘기는 값이 인자. "○○으로 볶음밥"의 ○○ 자리처럼 — 넣는 재료에 따라 결과가 달라짐.

📌 참고  매개변수(받을 자리, 정의 시)와 인자(넘기는 값, 호출 시)는 짝. 기본값을 정하면(def 인사(이름, 인사말="안녕")) 그 인자를 생략 가능. 기본값 매개변수는 없는 것 뒤에 와야 함.
3줄 요약
  1. 매개변수는 값 받는 자리, 인자는 넘기는 실제 값.
  2. 인자는 매개변수에 순서대로 담겨 함수 안에서 쓰임.
  3. 기본값을 정하면 해당 인자를 생략할 수 있음.
인터랙티브 · 할인가 함수

가격·할인율을 바꿔, 같은 함수가 다른 인자로 다른 결과를 내는 걸 봄.

12-3

return — 결과 돌려주기

print가 화면에 "보여주기"만 한다면, return은 결과 값을 돌려주어 변수에 담거나 계산에 쓰게 함. 둘을 혼동하는 게 가장 흔한 입문 실수.

📌 참고  return 값은 값을 돌려주고 함수를 즉시 끝냄. print만 한 함수를 변수에 담으면 None(돌려준 값 없음). 여러 값은 return a, b로 튜플 반환 → 언패킹으로 받음(Part 6). 데이터 분석은 거의 항상 return.
3줄 요약
  1. return은 결과를 호출한 쪽으로 돌려줌(함수도 끝냄).
  2. print(보여주기)와 return(돌려주기)은 다름.
  3. 여러 값은 return a, b로 튜플 반환.
인터랙티브 · return vs print

같은 계산을 return과 print로 만든 함수의 차이를 봄 — 돌려받은 값으로 또 계산할 수 있나?

12-4

스코프 — 이름이 사는 범위

함수 안에서 만든 변수는 함수 안에서만 살아 있음(지역 변수). 밖에선 안 보이고, 함수가 끝나면 사라짐. 각 함수가 독립된 작업대를 갖는 셈 — 서로 간섭하지 않아 안전함.

📌 참고  같은 이름(임시·결과)을 여러 함수에서 써도 충돌 없음(각자의 작업대). 바깥 값이 필요하면 전역 의존보다 매개변수로 받기 — "받은 것으로 일하고 결과를 return"이 깔끔.
3줄 요약
  1. 함수 안에서 만든 변수(지역)는 함수 안에서만 유효.
  2. 함수가 끝나면 지역 변수는 사라지고 밖에선 안 보임.
  3. 스코프 덕에 함수들이 서로 간섭 없이 독립 동작.

12-5

함수 + 반복 — 묶어 재사용

"한 건 처리"를 함수로 묶고, 반복으로 모든 데이터에 적용함. 규칙(함수)과 적용(반복)이 분리되어, 규칙을 바꿀 땐 함수 한 곳만 고치면 됨 — "진짜 프로그램다운" 구조.

📌 참고  "한 건을 어떻게 처리할지"는 함수로, "모든 건에 적용"은 반복으로 — 좋은 코드의 기본 패턴. 함수가 return하면 결과를 모아 누적·필터·정렬로 이어 갈 수 있음. 데이터 분석 코드 대부분이 이 형태.
3줄 요약
  1. "한 건 처리"를 함수로 묶고 반복으로 전체 적용.
  2. 규칙(함수)과 적용(반복)이 분리돼 수정·재사용 쉬움.
  3. return한 결과를 모아 다음 처리로 이어 감.
인터랙티브 · 판정 함수를 전체에 적용

"전체 실행"을 누르면, 판정(상품) 함수가 모든 상품에 차례로 적용됨.
