while과 반복 제어

for가 "정해진 묶음을 끝까지" 도는 반복이라면, while은 "조건이 참인 동안" 계속하는 반복. 그리고 break(멈춤)·continue(건너뛰기)로 반복을 더 정교하게 다룸.

🟠 흐름 제어 · 11/18 while · break · continue 예상 30분
11-1

while — 조건이 참인 동안

조건이 참인 동안 반복함. 동작은 검사 → (참이면) 실행 → 다시 검사의 되풀이. 반복 안에서 조건을 거짓으로 만드는 변화가 없으면 무한 루프가 됨.

⚠️ 무한 루프 주의  조건이 영원히 참이면 멈추지 않음. while을 쓸 땐 "반복 안에 조건을 거짓으로 만드는 변화(재고 -= 1 등)가 있는가?"를 꼭 확인. 노트북에서 무한 루프면 ■(정지)로 중단.
3줄 요약
  1. while 조건:은 조건이 참인 동안 반복함.
  2. 동작은 검사 → 실행 → 다시 검사의 되풀이.
  3. 조건을 거짓으로 만들 변화가 없으면 무한 루프.
인터랙티브 · while 한 바퀴씩

"한 바퀴"를 눌러, 조건 검사 → 실행 → 재고 감소가 반복되다 조건이 거짓이 되어 멈추는 걸 봄.

11-2

for vs while

핵심 기준은 "몇 번 돌지 미리 아는가". 묶음·정해진 횟수는 for, 조건이 만족될 때까지(횟수 모름)는 while. 데이터 처리는 대부분 for.

📌 참고  실무에선 for를 훨씬 자주 씀(데이터 순회가 대부분). while은 "입력 받기 반복", "수렴할 때까지 계산" 같은 특별한 경우. "처리할 묶음이 있으면 for, 조건으로 끝나면 while".
3줄 요약
  1. for는 묶음·정해진 횟수, while은 조건 기반.
  2. "몇 번 돌지 미리 아는가"가 선택 기준.
  3. 데이터 처리는 대개 for, while은 특별한 경우.
인터랙티브 · 상황별 선택

상황을 골라, for와 while 중 어느 것이 적합한지 봄.

11-3

break — 반복 멈추기

반복을 즉시 완전히 멈추고 빠져나옴. 남은 값이 있어도 더 안 봄. "찾으면 멈춤"(탐색)이나 "더 처리할 필요 없음"에 씀.

📌 참고  "조건 맞는 첫 항목 찾기"는 for + if + break — 전체를 안 돌고 찾는 즉시 멈춰 효율적. while True: + break는 복잡한 종료 조건에 쓰는 흔한 패턴.
3줄 요약
  1. break는 반복을 즉시 완전히 멈추고 빠져나옴.
  2. if와 함께 "특정 조건이면 멈춤"으로 씀.
  3. "찾으면 멈춤" 탐색에 유용함.
인터랙티브 · 첫 프리미엄 찾고 멈춤

"한 단계씩"을 눌러, 가격을 검사하다 첫 10만 이상을 만나면 break로 멈추는 걸 봄(이후는 안 봄).

11-4

continue — 이번 것만 건너뛰기

반복을 멈추는 게 아니라 이번 회차만 건너뛰고 다음 값으로 넘어감. break가 줄을 떠나는 것이라면, continue는 한 명만 건너뛰고 줄은 계속.

📌 참고  차이 — break는 반복을 끝냄(이후 안 봄), continue는 이번 것만 건너뜀(다음은 계속 봄). "잘못된·빈·관심 밖 값 건너뛰기"가 대표 쓰임(데이터 정제).
3줄 요약
  1. continue는 이번 회차만 건너뛰고 다음으로.
  2. break는 종료, continue는 다음 회차 계속.
  3. "잘못된·관심 밖 값 건너뛰기"에 유용함.
인터랙티브 · 잘못된 값 건너뛰기

"한 단계씩"을 눌러, 0 이하 값은 continue로 건너뛰고(취소선) 유효 값만 합산되는 걸 봄.

합계 = 0
11-5

종합 — 거르고·멈추고·처리

for + continue + break + 조건을 결합. "품절은 건너뛰고(continue), 첫 판매가능 프리미엄을 찾으면 멈춤(break), 나머지는 검토"하는 실전 흐름.

📌 참고  거르고(continue)·멈추고(break)·처리(반복)가 한 반복에 결합됨. 흐름 제어(Part 9~11) 도구가 모두 갖춰졌음. 복잡해지면 다음 단계의 함수로 분리해 읽기 쉽게 만듦.
3줄 요약
  1. for/while + break/continue + 조건으로 유연하게 처리.
  2. continue로 거르고, break로 멈추고, 나머지 처리.
  3. 복잡해지면 함수로 분리함(다음 단계).
인터랙티브 · 실전 처리 흐름

"한 단계씩"을 눌러, 품절은 건너뛰고 프리미엄을 찾으면 멈추는 정교한 반복을 봄.
