반복문 (for)

자동화의 심장. for는 "리스트의 모든 값을 하나씩 꺼내" 같은 처리를 자동으로 되풀이함. 조건문(Part 9)과 만나면, Part 8에서 손으로 하던 조회·집계·정렬·필터가 데이터가 몇 개든 한 번에 처리됨 — 데이터 분석 자동화의 본질.

10-1

for — 하나씩 꺼내 반복

for 변수 in 묶음:은 묶음(iterable)에서 값을 하나씩 꺼내 변수에 담고 들여쓴 코드를 실행함 — 더 꺼낼 값이 없을 때까지. 컨베이어 벨트처럼 값이 하나씩 옴.

📌 참고  리스트·문자열·딕셔너리 등 "반복 가능한(iterable)" 것이면 모두 같은 방식으로 순회됨. Part 8에서 목록[0],[1]… 손으로 쓰던 걸 for 상품 in 상품목록: 한 줄이 대신함.
3줄 요약
  1. for 변수 in 묶음:은 값을 하나씩 꺼내 반복.
  2. 리스트·문자열·딕셔너리 등 iterable이면 순회 가능.
  3. 손으로 하나씩 쓰던 것을 한 줄로 자동화함.

10-2

range — 숫자 범위로 반복

range(n)은 0부터 n−1까지 숫자를 내어 줌(끝 불포함 — 슬라이싱과 같은 약속). 횟수 반복이나 연속 숫자가 필요할 때 씀.

📌 참고  range(3)은 3개(0,1,2) — 끝 불포함. 반복 변수를 안 쓰면 관례로 _(밑줄). 값이 필요하면 for 값 in 리스트:, 위치가 필요하면 range(len(...)).
3줄 요약
  1. range(n)은 0~n−1 숫자를 내어 줌(끝 불포함).
  2. range(시작,끝,간격)으로 범위·간격 조절.
  3. 횟수 반복에 씀, 값만 필요하면 직접 순회가 깔끔.
인터랙티브 · range 실험

10-3

누적과 집계

빈 그릇(0 또는 [])에서 시작해 반복하며 +=/.append()로 쌓음. Part 8에서 값을 일일이 꺼내 모으던 걸 for가 자동으로 해 줌.

📌 참고  누적 변수는 반복 밖에서 초기화(총합=0), 반복 안에서 채움 — 안에서 초기화하면 매번 리셋되는 실수가 흔함. 단순 합계는 sum()이 간단하지만, 조건부 합계·가공 모으기엔 누적 패턴이 빛남.
3줄 요약
  1. 누적은 빈 그릇(0/[])에서 시작해 채우는 패턴.
  2. 합계는 +=, 모으기는 .append().
  3. 조건부 집계·가공 모으기에 강력함.

10-4

for + if — 필터 자동화

반복문 안에 조건문을 넣어 각 값을 검사해 맞는 것만 처리함. Part 8에서 손으로 하던 필터가 자동화됨 — 데이터가 몇 개든 한 번에.

📌 참고  Part 9의 단건 판정을 for로 감싸면 전체에 자동 적용됨 — "한 건 처리 규칙(if) + 되풀이(for) = 전체 자동화". 상품이 4개든 4만 개든 코드는 그대로.
3줄 요약
  1. for + if로 각 값을 검사해 맞는 것만 처리.
  2. 조건 통과한 것만 append로 모으면 필터.
  3. 단건 판정 + 반복 = 전체 데이터 자동 처리.
인터랙티브 · 재고 있는 상품만 (필터)

"한 단계씩"을 눌러, 각 상품의 재고를 검사해 통과(초록)/탈락(흐림)을 봄.

10-5

딕셔너리 순회

딕셔너리도 for로 순회. 그냥 돌리면 키가 나오고, 값은 .values(), 키-값 짝은 .items() + 언패킹(Part 6·7이 결합).

📌 참고  딕셔너리를 그냥 for x in 딕트:로 돌리면 키가 나옴(값 아님 — 주의). for 키, 값 in 딕트.items():가 딕셔너리 처리의 가장 흔한 패턴. 순회+조건+누적이면 데이터를 자유롭게 분석함.
3줄 요약
  1. 딕셔너리를 for로 돌리면 키가 나옴.
  2. .items() + 언패킹으로 키-값 둘 다 처리.
  3. 순회 + 조건 + 누적으로 데이터를 자유롭게 분석.

while과 반복 제어

for가 "정해진 묶음을 끝까지" 도는 반복이라면, while은 "조건이 참인 동안" 계속하는 반복. 그리고 break(멈춤)·continue(건너뛰기)로 반복을 더 정교하게 다룸.
