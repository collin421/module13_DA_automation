조건문·반복문·함수·컴프리헨션을 총동원해, Part 8의 상품 관리를 완전 자동화한 버전으로 재구현. 가장 큰 차이 — 이제 상품이 몇 개든 코드가 그대로임.

🟠 캡스톤 · 15/18 데이터 · 함수 · 적용 · 리포트 예상 40분
15-1

설계 — 데이터와 함수 나누기

자동화 설계는 데이터(무엇을)·함수(어떻게)·적용(반복)을 나누는 것. 규칙이 함수로 모이면 바꾸기 쉽고, 데이터에 일괄 적용하기 쉬움 — 데이터가 늘어도 코드는 그대로.

📌 참고  Part 8에서는 상품목록[0],[1]… 손으로 꺼냈음. 이번엔 함수와 반복으로 다룸 — 셔츠(5번째)를 추가해도 코드를 늘릴 필요가 없음. "데이터가 늘어도 코드는 그대로"가 자동화의 핵심 이득.
3줄 요약
  1. 자동화 설계는 데이터·함수(규칙)·적용(반복)을 나누는 것.
  2. 데이터는 딕셔너리들의 리스트, 규칙은 함수로.
  3. 분리하면 데이터가 늘어도 코드는 그대로임.
자동화의 3요소 분리

데이터·규칙·적용이 어떻게 나뉘는지 봄. 이 분리가 확장 가능한 코드의 핵심.

① 데이터 (무엇을)
상품목록 = [{"이름":"니트","가격":89000,...}, ...] # 딕셔너리들의 리스트
↓
② 처리 규칙 (어떻게) — 함수
def 재고상태(s): ... def 할인가(s): ...
↓
③ 적용 — 반복 / 컴프리헨션
for s in 상품목록: ... [... for s in 상품목록 if ...]
15-2

집계 자동화

Part 8에서 값을 손으로 나열하던 집계를, 컴프리헨션 + 집계 함수로 한 줄씩 자동화. 상품이 몇 개든 같은 코드로 총합·평균·최고·최저를 구함.

📌 참고  [s["가격"] for s in 상품목록] — 상품이 5개로 늘어도 이 코드 그대로 정확히 동작. Part 8에서 [목록[0]["가격"], 목록[1]["가격"], ...] 손으로 나열하던 것과 결정적 차이.
3줄 요약
  1. 컴프리헨션으로 한 속성을 뽑아 집계 함수에 넣음.
  2. 상품 개수가 늘어도 같은 코드로 정확히 동작.
  3. Part 8의 손 집계가 한 줄씩으로 자동화됨.
인터랙티브 · 한 줄로 요약

집계를 골라, 컴프리헨션으로 뽑은 값을 내장 함수로 요약하는 걸 봄.

15-3

분류와 필터 자동화

단건 판정을 함수로 만들고, 반복·컴프리헨션으로 모든 상품에 자동 적용. 판정 함수를 필터 조건에 그대로 재사용하는 점이 우아함.

📌 참고  "한 건 판정 함수 + 컴프리헨션 필터"가 데이터 분석에서 가장 자주 쓰는 결합. 판정 규칙을 함수로 두면 출력·필터·분류 어디에나 재사용. 범주별 개수는 .get(키, 0) + 1 누적 패턴(Part 7).
3줄 요약
  1. 단건 판정을 함수로 만들고 반복·컴프리헨션으로 적용.
  2. 판정 함수를 필터 조건에 재사용해 우아하게.
  3. 범주별 개수는 .get() 누적 패턴으로 셈.
인터랙티브 · 판정 함수 + 필터

필터를 골라, 재고상태() 함수가 전체에 적용되어 분류되는 걸 봄.

15-4

정렬과 리포트

가공한 데이터를 sorted+람다로 정렬하고, enumerate로 순위를 매겨, f-string으로 보기 좋은 리포트를 만듦. 리포트를 함수로 두면 어떤 목록이든 같은 요약을 뽑음.

📌 참고  정렬 → 순위(enumerate) → 리포트(f-string)는 분석 결과를 사람이 읽을 형태로 만드는 전형적 흐름. 리포트를 함수로 만들면 "월별 매출 리포트"처럼 반복 작업을 자동화하기 좋음.
3줄 요약
  1. sorted+람다로 정렬, enumerate로 순위.
  2. f-string으로 보기 좋은 리포트 문장을 만듦.
  3. 리포트를 함수로 두면 어떤 목록이든 같은 요약.
인터랙티브 · 정렬 + 순위 리포트

정렬 기준을 골라, 순위가 매겨진 리포트가 생성되는 걸 봄.

15-5

종합·회고 — Part 8과 무엇이 달라졌나

핵심은 "데이터가 늘어도 코드는 그대로", "규칙은 함수 한 곳에". Part 0~14에서 배운 모든 것이 하나의 자동화 프로그램으로 모였음.

  1. 데이터·함수·적용·리포트로 나뉜 자동화 골격 완성.
  2. Part 8 대비 — 데이터 늘어도 코드 그대로, 규칙은 한 곳.
  3. 이 구조가 데이터 분석 자동화의 표준 형태.
인터랙티브 · 상품 추가해도 코드 그대로

"상품 추가"를 눌러 데이터를 늘려도, 같은 리포트 코드가 자동 반영되는 걸 봄.
