자료구조
미니 프로젝트

Part 4~7의 자료구조를 하나로 묶어 작은 상품 관리 프로그램을 만듦. "딕셔너리들의 리스트"로 데이터를 설계하고 조회·집계·정렬·필터를 구현함 — 데이터 분석 자동화의 축소판.

🟡 캡스톤 · 8/18 조회 · 집계 · 정렬 · 필터 예상 35분
8-1

설계 — 데이터 담기

프로그램의 첫걸음은 자료구조 설계. "여러 상품 × 여러 속성"은 딕셔너리들의 리스트로 — 바깥은 리스트(순서·추가), 각 상품은 딕셔너리(의미 있는 키).

📌 참고  설계가 좋으면 그다음 코드가 쉬워짐. "이 데이터의 자연스러운 형태는?"을 먼저 물음. 키 이름은 모든 상품이 같게 — 그래야 조회·집계가 안정적임.
3줄 요약
  1. 프로그램의 첫걸음은 자료구조 설계임.
  2. "여러 건 × 여러 속성"은 딕셔너리들의 리스트로.
  3. 바깥 리스트(순서·추가), 각 건 딕셔너리(의미 있는 키).
우리의 데이터 (상품목록)

이 데이터를 아래 위젯들에서 조회·집계·정렬·필터함. 상품목록[번호]["키"] 구조.

상품목록 = [ {…}, {…}, {…}, {…} ] # 딕셔너리 4개의 리스트, len = 4
8-2

조회 — 원하는 값 꺼내기

상품목록[번호]["키"]로 바깥(번호) → 안(키) 두 단계로 꺼냄. f-string으로 여러 속성을 한 문장으로 정리함.

📌 참고  조회 결과를 변수에 담으면(상품 = 상품목록[0]) 그 뒤 코드가 짧아짐. f-string 안에서 키를 쓸 땐 바깥/안 따옴표를 다르게 — f"{상품['이름']}".
3줄 요약
  1. 상품목록[번호]["키"]로 바깥→안 조회.
  2. 조회한 한 건을 변수에 담으면 코드가 짧아짐.
  3. f-string으로 여러 속성을 보고 문장으로 정리.
인터랙티브 · [번호]["키"]

상품 번호와 속성(키)을 골라, 그 값을 꺼내는 코드와 결과를 봄.

8-3

집계 — 요약값 구하기

한 속성의 값만 모아 sum·max·min·len에 넣음. 총합·평균·최고·최저가 한눈에. (값 모으기를 자동화하는 게 반복문 — Part 10.)

📌 참고  "전체에서 한 속성만 뽑아 모은 뒤 집계"가 데이터 분석의 기본 동작(매출 합계·평균 단가). 평균은 sum/len, 개수는 len, 최고/최저는 max/min.
3줄 요약
  1. 집계는 한 속성 값만 모아 내장 함수에 넣는 것.
  2. sum·max·min·len으로 합계·최대·최소·개수·평균.
  3. 값 모으기를 자동화하는 것이 반복문임.
인터랙티브 · 가격/재고 집계

집계할 속성을 골라, 그 속성의 합계·평균·최대·최소를 봄.

8-4

정렬 — 기준에 따라 줄 세우기

sorted(상품목록, key=...)로 가격순·재고순 정렬. key=lambda 상품: 상품["가격"]은 "가격을 기준으로"라는 뜻(람다는 Part 13). reverse=True로 내림차순.

📌 참고  정렬 후 슬라이싱으로 "상위 N개"(비싼순[:2]). sorted()는 새 리스트라 원본은 그대로(Part 5). "비싼 순 TOP 5", "재고 적은 순"이 단골 작업임.
3줄 요약
  1. sorted(리스트, key=...)로 기준을 정해 정렬.
  2. key=lambda 상품: 상품["가격"]은 가격 기준.
  3. reverse=True 내림차순, 슬라이싱으로 상위 N개.
인터랙티브 · 기준 바꿔 정렬

정렬 기준을 골라 상품이 다시 줄 서는 걸 봄(표가 재정렬됨).

8-5

필터 — 조건에 맞는 것만

조건(Part 2 비교·논리)으로 데이터를 거름 — "재고 5 이하", "10만 이상" 등. 체로 거르듯 조건을 통과하는 것만 남김. (조건에 맞는 것만 한 줄로 모으기는 Part 14 컴프리헨션.)

📌 참고  상품 4개라 일일이 봤지만, 1000개라면? 같은 일을 손으로 못 씀 → 반복문(Part 9~)이 "1000개를 한 번에 처리"하는 힘을 줌. 지금의 번거로움이 다음 단계의 이유.
3줄 요약
  1. 필터는 조건(비교·논리)으로 데이터를 거르는 핵심 동작.
  2. 자료구조 + 조회·집계·정렬·필터 = 작은 분석 프로그램.
  3. 데이터가 많아지면 반복문·함수가 필요해짐.
인터랙티브 · 조건 필터

조건을 골라, 통과하는 상품(강조)과 걸러지는 상품(흐림)을 봄.

🎉
