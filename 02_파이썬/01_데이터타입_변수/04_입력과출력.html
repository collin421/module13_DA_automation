print 더 잘 쓰기

쉼표 ,로 여러 값을 한 번에 출력하고, sep(값 사이)·end(출력 끝)로 모양을 다듬음. 기본은 사이에 공백, 끝에 줄바꿈임.

📌 참고  쉼표 , 출력은 자동으로 공백을 넣고 숫자도 형변환 없이 섞을 수 있어 빠른 확인용으로 편함(문자열 +는 str() 필요). 보기 좋은 문장은 f-string(3-4)이 더 깔끔함.

  1. print에 쉼표로 여러 값을 넘기면 공백으로 이어 출력함.
  2. sep은 값 사이, end는 출력 끝(기본 줄바꿈)을 정함.
  3. 쉼표 출력은 숫자·문자를 형변환 없이 섞을 수 있음.

input — 사용자에게 값 받기

input("안내문구")는 문구를 보여 주고 입력을 기다림. 사용자가 친 값을 받아 변수에 담아 씀 — 코드가 사람과 대화하는 창구임.

📌 참고  노트북·온라인 환경에서 input()을 실행하면 입력창이 뜨고, 엔터를 눌러야 다음으로 진행됨. 노트북 실습에선 값을 직접 지정해 같은 흐름을 연습하는 예시도 함께 제공함.
3줄 요약
  1. input()은 사용자가 입력한 값을 받아 옴.
  2. 안내 문구를 보여 주고 입력(엔터)을 기다림.
  3. 받은 값을 변수에 담아 코드를 유연하게 만듦.
인터랙티브 · 입력 흐름 따라가기

input은 문자열 — 형변환

⚠️ 가장 중요한 주의점 — input()으로 받은 값은 무조건 문자열임. 숫자를 입력해도 "100"처럼 들어옴. 계산하려면 int()로 감싸야 함.

📌 참고  입력값으로 계산이 안 되면 십중팔구 "문자열인데 숫자처럼 보여서"임 — int()/float()로 감쌌는지 확인. 이름·상품명처럼 계산 안 할 값은 변환 불필요, 계산할 값만 변환함. int(input(...)) 패턴을 익혀 둘 것.
3줄 요약
  1. input()으로 받은 값은 무조건 문자열임.
  2. 계산하려면 int()·float()로 숫자로 바꿔야 함.
  3. int(input(...)) 패턴을 익혀 두면 편함.
인터랙티브 · 변환 전 vs 후

입력값 "3"으로 + 1을 해 봄. 그냥 더할 때(오류)와 int()로 바꿔 더할 때를 비교.

f-string — 값을 문구에 끼워 넣기

따옴표 앞에 f, 문장 속 {변수} 자리에 값이 들어감. 빈칸 채우기 양식처럼 깔끔하고, 형변환이 필요 없음.

📌 참고  f-string은 형변환이 필요 없고, {} 안에서 계산도 됨(예: {가격*0.9}). 파이썬에서 문장을 만드는 사실상 표준 방법으로, 데이터 분석 결과를 보고 문장으로 만들 때 거의 항상 씀.
3줄 요약
  1. f-string은 f + 문장 속 {변수}로 값을 끼워 넣음.
  2. 형변환이 필요 없고, {} 안에서 계산도 됨.
  3. 파이썬에서 문장을 만드는 사실상 표준 방법임.
인터랙티브 · 빈칸 채우기

상품명·가격을 바꾸면, f-string 양식의 {} 자리에 값이 채워져 문장이 완성됨.

f"{상품명}의 가격은 {가격}원"

3-5

f-string 다듬기 — 천 단위·소수점

{값:형식}으로 출력 모양을 다듬음. 맨숫자에 콤마라는 옷을 입히고, 긴 소수를 단정하게 정리함. 자주 쓰는 둘 — 천 단위 콤마와 소수점 자릿수.

📌 참고  형식은 종류가 많지만 입문 단계엔 콤마 ,와 소수점 .2f 둘이면 충분함. 형식 지정은 보이는 모양만 바꿀 뿐 변수에 담긴 값 자체는 그대로임.
3줄 요약
  1. {값:형식}으로 출력 모양을 다듬음.
  2. 천 단위 콤마 {값:,}, 소수점 {값:.2f}가 자주 쓰임.
  3. 형식 지정은 보이는 모양만 바꾸고 값 자체는 그대로임.
인터랙티브 · 형식 비교

같은 값에 형식을 켜고 끄며, 보이는 모양이 어떻게 달라지는지 봄(값 자체는 그대로).
