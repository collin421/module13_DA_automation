연산자

값들로 계산하고 판단하는 도구. 사칙연산, 나눗셈 삼형제(/ // %), 크기를 견주는 비교 연산자, 조건을 묶는 논리 연산자, 값을 누적하는 할당 연산자까지. 1-4에서 본 비교가 데이터를 거르고 판단하는 힘으로 확장됨 — 자동화의 계산·판단 엔진.

2-1

산술 연산자 — 계산의 기본

숫자를 계산하는 기호. 수학과 거의 같되 곱하기 *, 나누기 /, 거듭제곱 **의 기호가 다름. 변수에 담긴 값으로 계산하는 것이 핵심 쓰임임.

📌 참고  매출 합계, 평균(합÷개수), 단가×수량 — 데이터 분석의 거의 모든 계산이 산술 연산자에서 시작됨. 복잡한 계산은 중간값을 변수에 담아 단계로 나누면 읽기 쉬움.
3줄 요약
  1. 산술 연산자: + - * / ** (곱·나눗·거듭제곱 기호 주의).
  2. 변수에 담긴 값으로 계산하는 것이 핵심 쓰임임.
  3. 결과 자료형은 정수·실수 규칙을 따름.

두 수와 연산자를 골라 결과를 봄. 거듭제곱 **은 "곱하기를 여러 번"임.

2-2

나눗셈 삼형제 — / // %

/는 보통 나누기(항상 실수), //는 몫(소수점 버림), %는 나머지. 사탕 17개를 5명에게 나눌 때 — 한 명당 몇 개(//), 남는 건 몇 개(%), 정확히 나누면(/).

📌 참고  %(나머지)는 데이터 분석에서 의외로 자주 등장함 — "N개마다 한 번", 짝/홀 구분(% 2), 요일 계산 같은 주기·반복 패턴의 핵심 도구임.
3줄 요약
  1. 나눗셈 삼형제: /(실수)·//(몫)·%(나머지).
  2. /는 항상 실수, //는 묶음 개수, %는 나머지·주기.
  3. % 2로 짝수(0)·홀수(1)를 판별함.

2-3

비교 연산자 — 크기를 견주다

두 값을 견줘 참(True)·거짓(False)을 돌려줌. 양팔 저울처럼 어느 쪽이 큰지·같은지 판정함. 이 비교가 데이터를 거르는 필터의 기준이 됨.

📌 참고  =(담아라)와 ==(같은가?)를 반드시 구분! 비교 결과를 변수에 담아 두면 코드가 읽기 쉬워짐 — 예: 프리미엄 = 가격 >= 100000.
3줄 요약
  1. 비교 연산자(> < >= <= == !=)는 참/거짓을 돌려줌.
  2. =(담아라)와 ==(같은가?)를 구분함.
  3. 비교는 데이터를 거르는 필터의 기준이 됨.

2-4

논리 연산자 — 조건을 묶다

and(둘 다)·or(하나라도)·not(반대)으로 여러 참/거짓을 조합함. "가격이 싸고 재고가 있으면"처럼 일상의 조건 묶음을 코드로 옮긴 것 — 복합 필터의 핵심.

📌 참고  규칙은 단순함 — and는 모두 참이어야 참, or는 하나라도 참이면 참, not은 반대. 파이썬은 &&·|| 대신 영어 단어를 써서 읽기 쉬움.
3줄 요약
  1. 논리 연산자 and(둘 다)·or(하나라도)·not(반대)으로 조건을 묶음.
  2. 여러 비교를 엮어 복합 필터 조건을 만듦.
  3. 일상어("그리고/또는/아니다")로 읽으면 쉬움.
인터랙티브 · 조건 묶기 실험

두 조건(A·B)의 참/거짓을 눌러 바꾸고, and/or/not의 결과를 봄.

A = 가격>=5만
B = 재고>0
2-5

할당 연산자와 우선순위

+=는 "지금 든 것에 더해라"(저금통). 값을 누적·갱신하는 짧은 표현임. 그리고 여러 연산이 섞이면 계산 순서가 있음 — 괄호가 가장 먼저, 곱·나눗이 덧·뺄보다 먼저.

📌 참고  우선순위를 다 외울 필요 없음 — 헷갈리면 괄호를 쓰면 됨. 괄호는 의도를 분명히 하고 실수를 줄임. 합계·누적은 총합 = 0에서 +=로 쌓는 패턴이 정석(반복문에서 핵심).
3줄 요약
  1. += 등 할당 연산자로 값을 짧게 누적·갱신함.
  2. 연산은 괄호 → 거듭제곱 → 곱·나눗 → 덧·뺄 → 비교 → 논리 순.
  3. 헷갈리면 괄호로 순서를 명시하면 됨.
