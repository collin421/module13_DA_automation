변수와 자료형

print로 값을 띄우는 데서 나아가, 이제 값을 저장하고 다룸. 데이터를 담는 상자 변수와, 그 안에 담기는 데이터의 종류 자료형(숫자·문자열·불리언)을 익힘. 데이터 분석 자동화의 첫 벽돌 — "데이터를 코드로 담는 법"임.

변수 — 데이터를 담는 상자

변수는 데이터를 담는 이름표 붙은 상자임. =로 값을 담는데, 이건 "같다"가 아니라 "오른쪽 값을 왼쪽 상자에 담아라"는 명령임. 상자 내용은 새 값을 담아 언제든 바꿀 수 있음(재할당). 더 정확히는 — 값(89000)은 메모리에 만들어지고, 변수 이름이 그 값을 가리킴(바인딩). 그래서 재할당은 이름표를 새 값으로 옮겨 붙이는 것임.

📌 참고  변수 이름은 의미가 드러나게 지음 — x보다 price, p보다 discount_price. 데이터 분석에선 수많은 값을 다루므로, 이름만 봐도 내용을 알 수 있게 짓는 습관이 코드를 읽기 쉽게 만듦.
3줄 요약
  1. 변수는 데이터를 담는 이름표 붙은 상자임.
  2. =는 "같다"가 아니라 "오른쪽을 왼쪽 상자에 담아라"임.
  3. 새 값을 담아 언제든 바꿀 수 있음(재할당).
인터랙티브 · 상자에 값 담기

값을 입력하고 "담기"를 누르면 상자가 채워짐. 새 값을 담으면 이전 값은 사라짐(재할당).

숫자형 — 정수와 실수

소수점 없으면 정수(int), 있으면 실수(float). 숫자형의 핵심은 계산이 된다는 것. 단, 정수와 실수를 섞어 계산하면 결과는 실수가 됨.

📌 참고  수량(재고·개수)은 보통 정수, 비율·평균·무게는 보통 실수임. "실수가 섞이면 결과도 실수"라는 성질을 알아야 계산 결과를 예측할 수 있음. 데이터 분석에서 가장 많이 다루는 자료형이 숫자임.
3줄 요약
  1. 숫자형엔 정수(int)와 실수(float)가 있음.
  2. 수량은 보통 정수, 비율·평균은 보통 실수임.
  3. 정수·실수를 섞어 계산하면 결과는 실수가 됨.
인터랙티브 · 할인가 계산기

가격(정수)과 할인율(실수)을 바꿔, 할인가가 어떻게 계산되는지 봄. 실수가 섞이면 결과에 소수점이 붙음.

가격 = (정수)
할인율 = 0.1 (실수)

문자열 — 글자 데이터

따옴표로 감싼 글자 묶음. 따옴표가 있으면 문자열, 없으면 숫자 — 같은 89000이라도 종류가 다름. 문자열끼리 +는 덧셈이 아니라 이어 붙이기(연결)임.

📌 참고  입력값이나 파일에서 읽은 데이터는 겉보기엔 숫자라도 문자열인 경우가 많음(예: "89000"). 계산하려면 숫자로 바꿔야 함(형변환, 아래 1-5). "왜 계산이 안 되지?"의 흔한 원인이 바로 숫자처럼 보이는 문자열임.
3줄 요약
  1. 문자열은 따옴표로 감싼 글자들의 묶음임.
  2. 따옴표가 있으면 문자열, 없으면 숫자 — 종류가 다름.
  3. 문자열 +는 덧셈이 아니라 이어 붙이기(연결)임.
인터랙티브 · + 의 두 얼굴

같은 +인데 자료형에 따라 동작이 다름. 토글해서 문자열 연결과 숫자 덧셈을 비교해 봄.

1-4

불리언 — 참과 거짓

True(참)·False(거짓) 두 값만 갖는 자료형. 더 중요한 건 비교의 결과가 불리언이라는 점 — 이 참/거짓이 나중에 조건문·필터의 핵심 재료가 됨.

📌 참고  =(담아라)와 ==(같은가?)를 구분! 재고 = 0은 0을 담는 것, 재고 == 0은 0인지 묻는 것(결과 True/False). 입문 단계의 흔한 실수임. 데이터 분석에서 불리언은 "가격 5만 이상인 것만" 같은 필터의 기준이 됨.
3줄 요약
  1. 불리언은 참(True)·거짓(False) 두 값만 갖는 자료형임.
  2. 두 값을 비교하면 그 결과가 불리언으로 나옴.
  3. 이 참/거짓이 조건문·필터의 핵심 재료가 됨.
인터랙티브 · 비교의 결과는 참/거짓

재고 수와 비교 기호를 바꿔, 그 결과가 True인지 False인지 봄.

1-5

type과 형변환

값의 종류를 확인하려면 type(), 종류를 바꾸려면 int()·float()·str()를 씀. 특히 숫자처럼 보이는 문자열을 숫자로 바꿔 계산하는 일이 자주 필요함.

📌 참고  input()(Part 3)이나 파일에서 읽은 데이터는 항상 문자열임. 그래서 "100"을 입력받아 계산하려면 반드시 int("100")으로 바꿔야 함. 데이터 분석에서 "숫자 컬럼인데 계산이 안 돼요"의 단골 원인이 숨은 문자열이며, 형변환으로 해결함.
3줄 요약
  1. type()으로 자료형을 확인함.
  2. int()·float()·str()로 자료형을 서로 바꿈.
  3. 입력·파일 데이터는 문자열이라, 계산하려면 숫자로 바꿔야 함.
인터랙티브 · 형변환 실험실

문자열 "100"을 그냥 더할 때와, 숫자로 바꿔 더할 때를 비교해 봄.
