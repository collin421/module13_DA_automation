왜 파이썬인가
데이터 분석 자동화의 첫걸음

문법을 외우기 전에 왜 파이썬을 배우는지부터 가슴에 새김. 이유가 분명해야 끝까지 집중할 수 있음. 이 수업은 단순한 코딩 강의가 아니라 데이터 분석 자동화로 가는 여정의 출발점임 — 가장 많이 쓰이고, 쉽고, 데이터·AI 시대의 중심인 파이썬을 왜 골랐는지 다섯 가지 이유를 깊이 살펴봄.

목적지 = 데이터 분석 자동화

이 강의의 최종 목적지는 데이터 분석 자동화임 — 사람이 엑셀로 일일이 하던 작업(모으고·정리하고·계산하고·그래프로·보고서로)을 코드 한 번으로 자동 처리하게 만드는 것. 프로그래밍의 본질이 바로 반복을 기계에게 넘기는 것이고, 데이터 작업이야말로 그 반복의 대명사임.

📌 참고  "한 번만 할 일"은 굳이 코드로 안 짜도 됨. 프로그래밍의 진짜 가치는 반복·대량·규칙적인 작업에서 나옴 — 데이터 분석은 그 셋을 모두 갖춰 자동화 효과가 가장 큰 분야임. 오늘 배우는 기초 문법은 그 자동화를 짓는 벽돌과 시멘트임.
3줄 요약
  1. 이 수업의 목적지는 데이터 분석 자동화임.
  2. 프로그래밍의 본질은 반복을 기계에게 넘기는 것임.
  3. 코드는 한 번 짜면 반복 비용이 0에 수렴함.
인터랙티브 · 수작업 vs 코드

같은 데이터 작업을 몇 번 반복하는지 슬라이더로 바꿔 봄. 수작업은 횟수만큼 시간이 늘지만, 코드는 한 번 짜면 거의 그대로임.

왜 파이썬 ① — 가장 많이 쓰고, 쉽고, 즉시 확인

8000개가 넘는 언어 중 왜 파이썬일까? 첫 이유는 가장 많이 쓰이고, 가장 쉽고, 즉시 확인하며 배우기 좋기 때문임. 세 가지를 탭으로 확인해 봄.

📌 참고  파이썬은 주요 인기 지표에서 수년째 1위권이며, 최근 AI·데이터 붐으로 사용률이 급상승해 입문자에게 가장 권장되는 첫 언어가 됨. "가장 인기"가 "모든 일에 최고"란 뜻은 아니지만, 입문·데이터·AI·자동화라는 우리 목적엔 거의 모든 면에서 최적임.
3줄 요약
  1. 파이썬은 세계에서 가장 인기 있고 가장 쉬운 언어임.
  2. 인터프리터 언어라 적자마자 실행해 결과를 봄(즉시 피드백).
  3. 이 즉시 확인이 학습과 데이터 탐색을 빠르게 함.

왜 파이썬 ② — 데이터 분석의 공용어, AI 시대의 중심

파이썬을 배우는 가장 직접적인 이유 — 데이터 분석의 사실상 표준 언어이며, 바이브코딩·AI 시대의 중심이기 때문임. 데이터 도구가 모두 파이썬 위에 있고, AI도 파이썬을 가장 잘 다룸.

📌 바이브코딩 시대엔 더 중요함  "AI가 코드를 짜 주는데 왜 배우나?" → AI 코드도 옳은지 읽고 검증할 줄 알아야 안심하고 씀(자동 운전 보조도 운전을 알아야 안전). AI는 파이썬을 가장 잘 짜고, 파이썬은 사람이 읽기 가장 쉬움. 가장 위험한 건 "AI가 짜 줬으니 그냥 쓰자"임 — 기초가 있어야 AI 코드를 읽고·의심하고·고칠 수 있음.
3줄 요약
  1. 파이썬은 데이터 분석의 표준 — 핵심 도구가 모두 그 위에 있음.
  2. 바이브코딩 시대에도 코드를 읽고 검증할 능력은 필수임.
  3. AI는 파이썬을 가장 잘 짜고, 사람이 읽기도 가장 쉬움.

왜 파이썬 ③ — 라이브러리와 가상환경: 거인의 어깨

파이썬은 남이 만든 강력한 도구를 가져다 쓰는 생태계가 세계 최고임. 직접 다 만들 필요 없이 라이브러리를 불러 쓰고, 프로젝트마다 도구를 분리하는 가상환경으로 깔끔하게 관리함.

📌 참고  지금은 "라이브러리 = 남이 만든 도구를 import로 가져다 씀", "가상환경 = 프로젝트별 전용 공구함" 정도만 알면 충분함. "이런 기능 직접 만들어야 하나?" 싶을 땐 먼저 검색해 봄 — 파이썬엔 이미 만들어진 라이브러리가 있을 확률이 매우 높음.
3줄 요약
  1. 라이브러리로 남이 만든 강력한 도구를 가져다 씀(거인의 어깨).
  2. 가상환경으로 프로젝트별 도구를 깔끔히 분리·관리함.
  3. 이 풍부한 생태계가 파이썬을 배우는 강력한 이유임.

첫 코드 — print

이유를 충분히 새겼으니 인생 첫 코드를 적어 봄. 화면에 글자를 띄우는 명령은 print임. 괄호 ( ) 안에 내용을 넣고, 글자는 따옴표 " "로 감쌈. 이 강의 실습은 한 줄씩 실행하는 노트북으로 제공됨(인터프리터의 장점을 살린, 데이터 분석가가 쓰는 환경).

📌 참고  따옴표를 빼먹거나 괄호를 안 닫으면 오류가 남. 오류는 잘못이 아니라 컴퓨터가 "이 부분을 못 알아듣겠어요"라고 알려 주는 안내임 — 입문 단계에서 오류는 친구. # 뒤에 적는 주석은 컴퓨터가 무시하는 사람용 메모로, 코드 설명이나 잠시 막아 두기에 씀.
3줄 요약
  1. print(...)는 괄호 안 내용을 화면에 출력함.
  2. 글자는 따옴표로 감싸고, 숫자는 그대로 씀.
  3. 오류는 고칠 곳 안내, # 뒤는 사람용 메모(주석)임.
