튜플과 세트

리스트의 사촌 둘 — 튜플(못 바꾸는 리스트, 불변)과 세트(중복 없는 묶음, 집합). 리스트와 닮았지만 성질이 달라, "왜 굳이 이런 게 필요한지"를 동작 원리와 함께 이해함.

🟡 자료구조 · 6/18 튜플 · 세트 · 집합연산 예상 30분
6-1

튜플 — 못 바꾸는 리스트

소괄호 ( )로 만드는 불변 묶음. 읽기(인덱싱·슬라이싱·in)는 리스트와 완전히 같고, 값 변경·추가·삭제만 안 됨(가변 메서드가 아예 없음).

📌 참고  "리스트 = 가변([ ]), 튜플 = 불변(( ))"이 핵심 대비. 값 1개 튜플은 쉼표 필수 — (5,). (5)는 그냥 숫자 5(괄호가 계산용으로도 쓰여서 구분 필요).
3줄 요약
  1. 튜플은 소괄호 ( )로 만드는 불변 묶음.
  2. 읽기는 리스트와 완전히 같음.
  3. 값 변경·추가·삭제만 안 됨.
인터랙티브 · 봉인된 튜플

읽기 버튼은 동작하지만, 바꾸기 버튼은 오류가 남(불변).

6-2

왜 튜플인가 — 언패킹

불변이라 "바뀌면 안 되는 값"을 안전하게 보장함. 그리고 여러 값을 묶고 한 줄로 풀어 담는 언패킹이 매우 편리함 — 실무에서 가장 자주 만나는 튜플의 모습.

📌 참고  변수 교환 a, b = b, a도 튜플 덕에 한 줄(다른 언어는 임시 변수 필요). 함수가 여러 값을 한꺼번에 돌려줄 때도 튜플이 쓰임(Part 12).
3줄 요약
  1. 튜플은 "바뀌면 안 되는 값"을 안전하게 보장함.
  2. 여러 값을 묶고 푸는 언패킹이 편리함.
  3. 변수 교환·함수의 여러 값 반환에 자연스럽게 쓰임.
인터랙티브 · 묶고 풀기(언패킹)

"언패킹 실행"을 누르면, 튜플의 값들이 각 변수로 나뉘어 담기는 걸 봄.

상품 = ("니트", 89000, 12)
↓ 이름, 가격, 재고 = 상품
6-3

세트 — 중복 없는 묶음

중괄호 { }, 중복 불허·순서 없음. 가장 큰 쓸모는 set(리스트)로 한 번에 중복 제거. 해시 방식이라 포함 확인(in)도 매우 빠름.

📌 참고  세트는 순서가 없어 인덱싱(세트[0]) 불가 — 순서가 필요하면 리스트. "고유한 값만", "포함 여부 빠르게"면 세트가 답. 해시 덕에 큰 데이터에서도 in이 거의 즉시임.
3줄 요약
  1. 세트는 중괄호 { }, 중복 불허·순서 없음.
  2. set(리스트)로 중복을 한 번에 제거함.
  3. 해시 방식이라 포함 확인(in)이 매우 빠름.
인터랙티브 · 중복 제거

"set() 적용"을 누르면 중복된 값이 사라지고 고유 종류만 남음.

구매상품 (리스트)
6-4

집합 연산

두 묶음을 비교해 교집합 &(공통)·합집합 |(전체)·차집합 -(차이)을 한 줄로 구함. 신규/이탈/유지 분석에 강력함.

📌 참고  지난달={니트,코트,가디건}, 이번달={코트,가디건,패딩}. 같은 일을 리스트로 하려면 반복문이 필요하지만(Part 10), 세트는 &·|·- 한 번이면 됨.
3줄 요약
  1. 세트는 교집합 &·합집합 |·차집합 -을 지원.
  2. 두 묶음의 공통·전체·차이를 한 줄로 구함.
  3. 신규/이탈/유지 분석에 특히 강력함.
인터랙티브 · 두 기간 비교

연산을 골라, 지난달·이번달 판매 상품의 공통·전체·차이를 봄.

이번달
6-5

네 자료구조 비교

문자열·리스트·튜플·세트 — 순서·가변·중복 성질이 다름. 기본은 리스트, "바뀌면 안 되네"(튜플), "중복 없애야 하네"(세트)처럼 특별한 이유가 생길 때 고름.

📌 참고  대부분 리스트로 충분함 — 튜플·세트는 분명한 이유가 있을 때 선택. 다음 파트의 딕셔너리까지 더하면 데이터 표현 도구를 모두 갖추게 됨.
3줄 요약
  1. 네 자료구조는 순서·가변·중복 성질이 다름.
  2. 기본은 리스트, 고정이면 튜플, 고유/집합이면 세트.
  3. 자료구조 선택은 데이터의 성격을 코드로 표현하는 일.
