파이썬 기초 문법 · Part 5 · 자료구조

리스트

여러 값을 순서대로 담는 가장 많이 쓰는 자료구조. 만들고·꺼내고·자르고(문자열과 닮음), 추가·삭제·정렬함. 그리고 핵심 동작 원리 — 문자열과 달리 리스트는 바꿀 수 있고(가변) 변수가 그것을 가리킨다(참조)는 점을 익힘.

🟡 자료구조 · 5/18 가변 · 참조 · 정렬 예상 35분
5-1

리스트 만들기

[ ] 안에 값을 쉼표로 나열한 순서 있는 묶음. 인덱싱·슬라이싱·len·in이 문자열과 똑같이 통함 — 새로 외울 게 적음.

📌 참고  빈 리스트는 []로 만들어 나중에 값을 채워 넣음(반복문에서 자주). Part 4의 .split() 결과가 바로 리스트였음 — "a,b,c".split(",") → ['a','b','c'].
3줄 요약
  1. 리스트는 [ ]에 값을 나열한 순서 있는 묶음.
  2. 인덱싱·슬라이싱·len·in이 문자열처럼 통함.
  3. .split()의 결과가 바로 리스트임.
인터랙티브 · 리스트 인덱싱

칸을 클릭해 인덱스를 확인. 문자열의 글자 대신 "값"이 들어 있을 뿐 동작은 같음.

5-2

가변과 참조 ⭐

리스트는 바꿀 수 있고(가변), 변수는 리스트를 가리킴(참조). 그래서 b = a는 복사가 아니라 같은 리스트를 둘이 함께 가리키는 것 — 한쪽을 바꾸면 양쪽이 바뀜.

📌 참고  b = a는 복사가 아니다 — 같은 리스트를 함께 가리킴(Part 1 바인딩과 같은 원리). 숫자·문자열은 불변이라 이런 일이 없지만, 리스트는 가변·참조라 주의. 따로 다루려면 .copy().
3줄 요약
  1. 리스트는 가변 — 인덱스로 값을 직접 바꿈.
  2. 변수는 리스트를 가리킴(참조) — b=a는 복사 아님.
  3. 따로 다루려면 .copy()로 진짜 복사.
인터랙티브 · b = a 는 복사가 아니다

"b = a"와 "b = a.copy()"를 비교. b를 바꿨을 때 a가 어떻게 되는지 봄.

5-3

추가와 삭제

.append(끝에 추가)·.pop(맨 끝 빼기)·.remove(값 삭제). 문자열과 정반대로, 리스트 메서드는 원본을 직접 바꿈(가변) — 그래서 다시 담지 않음.

📌 참고  ⚠️ 목록 = 목록.append("X")처럼 다시 담으면 안 됨 — .append()는 원본을 바꾸고 None을 돌려줘서, 다시 담으면 리스트가 사라짐. 그냥 목록.append("X")만.
3줄 요약
  1. append·insert·remove·pop으로 가공함.
  2. 리스트 메서드는 원본을 직접 바꿈 — 다시 담지 않음.
  3. 빈 리스트 → append로 채우는 패턴이 반복문에서 핵심.
인터랙티브 · 추가·삭제

버튼으로 리스트를 직접 가공해 봄. 원본이 그 자리에서 바뀜(다시 담지 않음).

5-4

정렬과 집계

.sort()(원본 정렬)·sorted()(새 리스트), 그리고 sum·max·min·len으로 합계·최대·최소·평균을 한 줄에. 데이터 분석의 단골 작업임.

📌 참고  .sort()는 원본을 바꿈, sorted()는 새 리스트를 돌려줌(원본 보존 시 사용). "비싼 순 상위 N개", "매출 합계·평균"이 정렬+슬라이싱, sum/len으로 바로 됨.
3줄 요약
  1. .sort()는 원본 정렬, sorted()는 새 리스트.
  2. reverse=True로 내림차순.
  3. sum·max·min·len으로 요약값을 구함.
인터랙티브 · 정렬 + 집계

정렬 버튼으로 막대를 정렬하고, 합계·평균 등 집계값을 확인.

5-5

중첩 리스트 — 표 만들기

리스트 안에 리스트를 담아 표(행·열)를 만듦. [행][열]로 두 번 인덱싱해 한 칸을 꺼냄. 이 "리스트의 리스트"가 데이터 분석의 기본 데이터 형태임.

📌 참고  "리스트의 리스트"가 CSV·데이터프레임의 바탕임. 중첩이 깊어지면 읽기 어려우니 실무에선 보통 2단계(표)까지 직접 다루고 그 이상은 pandas에 맡김.
3줄 요약
  1. 리스트 안에 리스트를 담아(중첩) 표 구조를 만듦.
  2. [행][열]로 두 번 인덱싱해 한 칸을 꺼냄.
  3. 이 "리스트의 리스트"가 데이터 분석의 기본 형태임.
인터랙티브 · 상품표 [행][열]

표의 칸을 클릭하면, 그 칸을 꺼내는 [행][열] 코드와 값이 나타남.
