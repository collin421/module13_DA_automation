데이터 분석
방법의 진화

1강이 "누가, 왜" 분석했는가의 역사였다면, 2강은 "어떤 방법으로" 분석했는가의 역사임. 분석의 무기는 단순한 것에서 강력한 것으로 진화해 왔음 — 그리고 핵심은 "진화는 대체가 아니라 누적"임.

2-1

분석 방법은 왜 진화했는가

분석 방법이 진화한 이유는 한마디로 사람들이 점점 더 어려운 질문에 답하고 싶어졌기 때문임. 질문이 어려워질수록 더 강력한 도구가 필요했음. 아래에서 질문의 난이도와 그에 필요한 방법을 짝지어 봄.

인터랙티브 · 질문이 진화하면 방법도 진화함

각 단계를 눌러, "어떤 질문"이 "어떤 방법"을 불렀는지 봄. 이 5단계가 2강의 전체 지도임.

①집계
②통계
③마이닝
④머신러닝
⑤딥러닝·AI

비유 — 점점 좋아지는 망원경

맨눈으로는 가까운 것만 보임(집계). 망원경을 쓰면 먼 별도 보임(통계). 더 좋은 망원경은 별의 색·구성까지 분석함(마이닝). 천체망원경은 새 은하를 발견함(ML·AI). 도구가 강해질수록 볼 수 있는 게 늘지만, 맨눈으로 보는 일이 사라지진 않음. 천문학자도 여전히 맨눈으로 밤하늘을 봄 — 이것이 "대체가 아니라 누적"의 뜻임.

📌 겁먹지 말 것
통계·마이닝·머신러닝·딥러닝이라는 말에 겁먹지 말 것. 지금은 각각을 깊이 배우는 게 아니라 "이런 단계들이 있고, 각각 이런 질문에 답하려 나왔구나" 하는 전체 지도를 그리는 시간임. 그리고 복잡한 방법이 항상 좋은 게 아님 — 단순한 질문엔 단순한 집계가 가장 빠르고 정확함.

3줄 요약
  1. 분석 방법은 사람들이 점점 더 어려운 질문에 답하려 하면서 진화했음.
  2. 집계→통계→마이닝→ML→딥러닝·AI 순으로 단순함에서 복잡함으로 발전했음.
  3. 지금은 각각을 깊이 배우기보다 전체 지도를 머릿속에 그리는 것이 목표임.
2-2

① 집계 — 세고 합치는 분석

분석의 첫 단계이자 가장 기본은 집계(aggregation)임. 어려운 말이 아님 — 세고(count), 합치고(sum), 평균 내고(average), 정리하는 것임. 1강 분식집의 "김밥 하루 평균 65인분"이 바로 집계임. 집계가 답하는 질문은 "무슨 일이 있었나?"임.

기술 통계(descriptive statistics)
집계에 쓰는 요약값들. 합계·평균·개수·최댓값·최솟값·중앙값 등. "기술(describe)"은 "데이터를 묘사·서술한다"는 뜻.

초보자가 꼭 알아야 할 "평균의 함정"

집계에서 가장 많이 쓰는 평균은, 때때로 사실을 왜곡함. 아래 위젯에서 직접 확인해 봄.

인터랙티브 · 평균의 함정

단체 손님(이상치) 한 명을 넣고 빼면서, 평균이 어떻게 출렁이는지 봄. 평균과 중앙값을 비교해 봄.

이상치(outlier)
다른 값들과 유난히 동떨어진 값. 평균은 이상치에 크게 흔들림. 이럴 땐 크기순 한가운데 값인 중앙값(median)이 "보통"을 더 잘 대표함.
📌 집계는 단순하지만 가장 많이 쓰임
실제 회사의 대부분 보고서·대시보드(매출 추이·방문자 수·가입자 수)는 집계로 이루어짐. 화려한 머신러닝보다 정확한 집계 하나가 더 큰 결정을 이끄는 경우가 훨씬 많음. 다만 "가진 데이터만 요약"할 수 있다는 한계가 다음 단계를 부름 — "5천만 명을 다 못 세는데, 일부로 전체를 추정할 순 없을까?"
3줄 요약
  1. 집계는 세고·합치고·평균 내어 요약하는, 가장 기본적이고 많이 쓰는 분석임.
  2. 평균은 이상치에 흔들리므로 중앙값 등과 함께 봐야 왜곡을 피함.
  3. "일부로 전체를 추정하고 싶다"는 한계가 다음 단계인 통계 분석을 부름.
2-3

② 통계 분석 — 일부로 전체를 추정

집계는 "가진 데이터"만 요약했음. 통계 분석은 한 걸음 더 나아가 "가진 일부(표본)로, 갖지 못한 전체(모집단)를 추정"함. 이것이 집계와의 결정적 차이임.

모집단(population)과 표본(sample)
· 모집단 = 진짜 알고 싶은 전체 (예: 국민 전체의 키)
· 표본 = 실제로 뽑아 조사한 일부 (예: 무작위 1,000명의 키)
→ 발상: 전체를 다 못 조사하니, 일부만 잘 조사해 전체를 추정하자.
인터랙티브 · 국 맛보기 비유

통계의 핵심 비유. 단계를 눌러, 왜 "잘 저은 한 숟가락"이 솥 전체를 대표하는지 봄.

표본을 잘못 뽑은 실패 사례 (1936년)
한 잡지사가 200만 명에게 설문해 미국 대선을 예측했지만 완전히 틀림. 전화·자동차 명단에서 뽑았는데, 당시 그건 부유층에 치우친 표본이었음(국의 위쪽만 뜬 셈). 표본은 크기보다 "전체를 골고루 대표하는가"가 중요함.

분포 — 데이터가 퍼진 "모양"

통계의 또 다른 핵심은 분포(distribution)임. 데이터가 어떤 값 주변에 얼마나 퍼져 있는지의 모양임. 키·점수 등 많은 현상이 가운데가 높고 양끝이 낮은 종 모양(정규분포)을 띰.

시각화 · 정규분포와 회귀

통계의 두 핵심 도구를 그림으로 봄. 버튼으로 전환해 봄.

신뢰구간 · 회귀
· 신뢰구간: 추정엔 오차가 있으므로 "평균 키는 170cm로 추정, 오차 감안 169~171cm일 가능성이 높음"처럼 범위와 불확실성을 함께 제시함.
· 회귀(regression): 데이터에 가장 잘 맞는 식(직선)을 그어, 모르는 값을 추정(예: 넓이로 집값 추정). → 머신러닝의 직접적 뿌리!
📌 다음 단계를 부르는 한계
통계는 보통 사람이 "이런 관계가 있을 것"이라 먼저 가설을 세우고 확인함. 그런데 데이터가 거대해지면 — "사람이 미처 생각 못 한 패턴이 이 안에 있지 않을까? 데이터 스스로 패턴을 드러내게 할 순 없을까?" 이 질문이 데이터 마이닝을 부름.
3줄 요약
  1. 통계 분석은 일부(표본)로 전체(모집단)를 추정하는 방법으로, 국 맛보기에 비유됨.
  2. 분포로 값의 의미를 해석하고, 신뢰구간으로 불확실성을 함께 제시함.
  3. 회귀는 데이터에 식을 맞춰 모르는 값을 추정하는 것으로, 머신러닝의 뿌리가 됨.
2-4

③ 데이터 마이닝 — 패턴 캐기

데이터 마이닝은 이름 그대로 "데이터를 캐낸다(mining)"는 뜻. 광부가 금을 캐듯, 거대한 데이터 더미에서 숨은 패턴·규칙을 캐냄. 통계와의 결정적 차이는 순서임.

통계 vs 데이터 마이닝 — 순서가 다름
· 통계: 사람이 먼저 가설 → 데이터로 확인 ("넓이가 가격에 영향 줄 것 같다 → 확인")
· 마이닝: 가설 없이 데이터를 뒤져서 → 숨은 패턴 발견 ("뭐가 있는지 일단 캐 보자")
인터랙티브 · 전설의 "맥주와 기저귀"

데이터 마이닝의 가장 유명한 사례. 단계를 눌러, 사람이 가설로 떠올리기 힘든 패턴을 데이터가 어떻게 드러내는지 봄.

인터랙티브 · 대표 기법 두 가지

데이터 마이닝의 두 대표 기법을 눌러 봄. 오늘날 추천·고객분류의 바탕임.

📌 다음 단계를 부르는 한계
마이닝은 주로 "과거에 이런 패턴이 있었다"를 발견함. 사람들은 곧 더 욕심을 냄 — "발견한 패턴으로 미래를 예측할 순 없을까? 이 고객이 떠날지를 자동으로 맞히게, 나아가 컴퓨터가 스스로 규칙을 학습하게 할 순 없을까?" 이 질문이 머신러닝을 부름.
3줄 요약
  1. 데이터 마이닝은 거대한 데이터에서 숨은 패턴·규칙을 캐내는 방법임.
  2. 통계와 달리 가설 없이 데이터를 뒤지며(맥주-기저귀), 연관 규칙·군집화가 대표 기법임.
  3. "패턴으로 미래를 예측하고 스스로 배우게 하고 싶다"는 욕구가 머신러닝을 부름.
2-5

④ 머신러닝 — 스스로 규칙을 학습

머신러닝(기계 학습)의 핵심을 한 문장으로 — 사람이 규칙을 일일이 정해 주는 대신, 컴퓨터가 데이터를 보고 스스로 규칙을 "학습"하게 하는 것. 왜 도약인지, 스팸 필터로 비교해 봄.

인터랙티브 · 스팸 메일 거르기 — 전통 방식 vs 머신러닝

두 방식을 눌러 비교해 봄. 누가 규칙을 만드는지가 핵심 차이임.

비유 — 아이에게 고양이 가르치기
"고양이"를 말로 정의하긴 어려움(귀 뾰족·수염… 강아지도 그런데?). 대신 고양이 사진을 여러 장 보여 주면 아이는 어느 순간 "고양이다움"을 스스로 터득해 처음 본 고양이도 맞힘. 머신러닝이 정확히 이렇게 작동함 — 예시(데이터)를 충분히 주면 규칙을 스스로 터득함.
인터랙티브 · 머신러닝의 두 갈래

두 갈래를 눌러 봄. 앞 단계(통계 회귀·마이닝 군집)가 여기로 이어지는 게 핵심!

📌 진화는 누적 — 앞 단계가 여기로 흐름
2-3의 회귀(데이터에 식 맞추기) → 머신러닝의 "지도 학습 - 회귀"로 발전. 2-4의 군집화(비슷한 것끼리) → 머신러닝의 "비지도 학습 - 군집"으로 이어짐. 머신러닝은 하늘에서 떨어진 게 아니라 통계·마이닝의 발상을 이어받은 것임.
3줄 요약
  1. 머신러닝은 사람이 규칙을 주는 대신, 데이터로 컴퓨터가 스스로 규칙을 학습하게 함.
  2. 지도 학습(분류·회귀)과 비지도 학습(군집)으로 나뉘며, 앞 단계의 회귀·군집을 이어받음.
  3. "복잡한 데이터에서 무엇을 볼지까지 스스로 알아내게 하고 싶다"가 딥러닝을 부름.
2-6

⑤ 딥러닝·AI, 그리고 "진화는 누적"

딥러닝(deep learning)은 머신러닝의 한 종류로, 특히 사진·음성·자연어처럼 아주 복잡한 데이터를 잘 다룸. "딥(깊은)"은 정보를 처리하는 층(layer)을 여러 겹 깊게 쌓았다는 뜻. 핵심 도약 — 사람이 "무엇을 볼지(특징)"를 골라 주지 않아도, 데이터에서 무엇이 중요한지까지 스스로 알아냄.

비유 — 신경망과 두뇌
두뇌가 빛 신호를 여러 단계로 처리해(선→모양→얼굴) "엄마다!"를 알아보듯, 딥러닝(인공 신경망)도 데이터를 여러 층으로 처리하며 점점 복잡한 특징을 스스로 잡아냄(사진: 선·점 → 눈·코 → 얼굴 전체).

AI·머신러닝·딥러닝의 관계 — 헷갈리지 않게

세 단어가 자주 섞여 초보자를 혼란스럽게 함. 이들은 포함 관계(큰 원 안에 작은 원)임. 아래 그림으로 정리함.

시각화 · 딥러닝 ⊂ 머신러닝 ⊂ AI

세 개념의 포함 관계를 한눈에 봄. 각 층을 눌러 설명을 봄.

인공지능 (AI)
사람처럼 똑똑하게 행동하는 모든 기술
머신러닝 (ML)
데이터로 스스로 규칙을 학습
딥러닝 (DL)
신경망을 깊게 쌓아 복잡한 데이터 처리

핵심 메시지 — "진화는 대체가 아니라 누적"

우리는 집계→통계→마이닝→ML→딥러닝·AI를 봤음. 그런데 뒤의 것이 앞의 것을 없앤 게 아님. 지금 이 순간에도 다섯 단계가 모두 함께 쓰임.

인터랙티브 · 한 회사에서 동시에 일어나는 일

각 항목을 눌러, 다섯 단계가 현실에서 어떻게 함께 쓰이는지 봄. 가장 많이 쓰는 건 여전히 ①②임!

비유 — 연장통
망치(집계)로 시작해 드라이버(통계)·드릴(마이닝)·정밀공구(ML)·첨단기계(딥러닝)가 차례로 연장통에 추가됨. 하지만 드릴이 생겼다고 망치를 버리지 않음 — 못 박을 땐 망치가 최고. 연장이 많아질수록 "어떤 일에 어떤 연장을 쓸지"의 안목이 더 중요해짐.
📌 도구에 휘둘리지 말 것
요즘 "AI"가 유행이라 모든 걸 AI로 풀어야 할 듯하지만, 현실의 수많은 문제는 단순 집계·통계로 더 빠르고 정확하게 풀림. "AI를 썼다"가 자랑이 아니라 "문제를 잘 풀었다"가 핵심임. 항상 "이 문제에 가장 적합한 방법이 무엇인가"를 먼저 물을 것.
3줄 요약
  1. 딥러닝은 신경망을 깊게 쌓아 복잡한 데이터를 다루는 머신러닝의 한 종류임(딥러닝⊂ML⊂AI).
  2. 분석 방법의 진화는 대체가 아니라 누적이며, 다섯 단계가 지금도 함께 쓰임.
  3. 가장 중요한 것은 도구의 개수가 아니라 문제에 맞는 방법을 고르는 안목임.
